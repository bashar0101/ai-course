الانتشار العكسي يحسب كل التدرّجات في تمرير واحد إلى الوراء.

وتكلفته تقريباً ضعف التمرير الأمامي، مهما كان عدد الأوزان.

backpropagation
الانتشار العكسي ليس طريقة تعلّم. هو فقط طريقة سريعة لحساب التدرّج. التعلّم نفسه هو النزول بالتدرّج.

قاعدة واحدة تكفي

نتخيل الشبكة رسم حساب: كل عملية عقدة، والأرقام تمر بين العقد.

computational graph

تذكّر قاعدة السلسلة من الدرس 8. عملية تأخذ a وتعطي q. إذا عرفنا تدرّج الخسارة بالنسبة لمخرجها، فتدرّجها بالنسبة لمدخلها:

∂L∂a=∂L∂q×∂q∂a

بالكلمات: التدرّج عند المدخل = التدرّج القادم × المشتقة المحلية.

upstream gradient × local derivative

كل عقدة تحتاج أن تعرف مشتقتها المحلية فقط. ولا تهتم بباقي الشبكة.

العمليةالمخرجالتدرّج لكل مدخل
جمعq=a+bالتدرّج القادم كما هو، لكليهما
ضربq=a×bالتدرّج القادم × المدخل الآخر
ريلوq=max⁡(0,a)التدرّج القادم إذا كان a موجباً، وإلا صفر
مربعq=a2التدرّج القادم × 2a

وقاعدة أخيرة: إذا ذهبت قيمة إلى أكثر من مكان، نجمع التدرّجات القادمة من كل الأماكن.

الصيغ لطبقة كاملة

في الشبكات الحقيقية لا نحسب عصبوناً عصبوناً. نستخدم المصفوفات، كما في الدرس السابق.

طبقة كاملة الاتصال: Y=XW+b. ولنسمِّ تدرّج الخسارة بالنسبة لمخرجها δ، بنفس شكل Y:

δ=∂L∂Y

عندها:

∂L∂W=X⊤δ
∂L∂b=∑iδi
∂L∂X=δ W⊤

الإزاحة: نجمع صفوف δ، لأن نفس الإزاحة أُضيفت لكل مثال.

والأخيرة هي التدرّج القادم للطبقة السابقة. وهي تجمع تلقائياً التدرّجات من كل العصبونات، حسب قاعدة الجمع.

التدرّجالحسابالشكل
∂L/∂W(din×n)(n×dout)din×dout، مثل W
∂L/∂bمجموع n صفاًdout، مثل b
∂L/∂X(n×dout)(dout×din)n×din، مثل X

وطبقة التفعيل تضرب عنصراً بعنصر في مشتقة الدالة:

∂L∂Z=∂L∂H⊙g′(Z)

الرمز ⊙ يعني ضرب كل عنصر في نظيره.

تحقق من مثالنا: X=(2)، و δ عند الطبقة المخفية (1,0). فيعطي X⊤δ=(2,0): نفس تدرّجي w1 و w2 اللذين حسبناهما بيدك.

حيلة الأشكال

نسيت الصيغة؟ تدرّج أي شيء له نفس شكله. رتّب المصفوفات، مع التبديل إذا لزم، حتى يخرج الشكل الصحيح. غالباً يوجد ترتيب واحد فقط يعمل.

tiny_backprop.pyبايثون
import numpy as np

x, y = 2.0, 1.0
w, b = np.array([0.5, -1.0]), np.array([0.0, 1.0])
v, c = np.array([1.0, 2.0]), 0.5

def forward(w, b, v, c):
    z = w * x + b
    h = np.maximum(0, z)
    y_hat = v @ h + c
    return z, h, y_hat, (y_hat - y) ** 2

z, h, y_hat, loss = forward(w, b, v, c)
print("forward : z =", z, " h =", h, " y_hat =", y_hat, " loss =", loss)

# backward, from the loss to the inputs
g_yhat = 2 * (y_hat - y)
g_v, g_c = g_yhat * h, g_yhat
g_h = g_yhat * v
g_z = g_h * (z > 0)          # ReLU: pass the gradient only where z > 0
g_w, g_b = g_z * x, g_z
print("grads   : w", g_w, " b", g_b, " v", g_v, " c", g_c)

lr = 0.1
w, b, v, c = w - lr * g_w, b - lr * g_b, v - lr * g_v, c - lr * g_c
print("new loss:", round(forward(w, b, v, c)[3], 4))

def loss_of(params):
    w, b, v, c = params[:2], params[2:4], params[4:6], params[6]
    return forward(w, b, v, c)[3]

params = np.array([0.5, -1.0, 0.0, 1.0, 1.0, 2.0, 0.5])
backprop = np.array([2, 0, 1, 0, 1, 0, 1], dtype=float)   # from the hand example

eps = 1e-5
numeric = np.zeros_like(params)
for i in range(len(params)):
    p_plus, p_minus = params.copy(), params.copy()
    p_plus[i] += eps
    p_minus[i] -= eps
    numeric[i] = (loss_of(p_plus) - loss_of(p_minus)) / (2 * eps)

print("numeric :", numeric.round(6))
print("max difference:", np.abs(numeric - backprop).max())

طبقات قابلة للتركيب

نكتب كل طبقة كصنف له تمرير أمامي يحفظ ما يحتاجه، وتمرير عكسي يحسب التدرّجات ويرجع التدرّج للطبقة السابقة.

هذا بالضبط تصميم مكتبات التعلّم العميق من الداخل:

layers.pyبايثون
class Linear:
    def __init__(self, d_in, d_out, rng):
        self.W = rng.normal(0, np.sqrt(2 / d_in), size=(d_in, d_out))
        self.b = np.zeros(d_out)

    def forward(self, X):
        self.X = X                       # keep the input for the backward pass
        return X @ self.W + self.b

    def backward(self, delta):
        self.dW = self.X.T @ delta
        self.db = delta.sum(axis=0)
        return delta @ self.W.T          # gradient for the previous layer

class ReLU:
    def forward(self, Z):
        self.mask = Z > 0
        return Z * self.mask

    def backward(self, delta):
        return delta * self.mask

نبني شبكة صغيرة منها، ونحسب التدرّجات لدفعة من 5 أمثلة، ونفحص تدرّج الطبقة الأولى عددياً:

layers_check.pyبايثون
rng = np.random.default_rng(0)
layers = [Linear(3, 4, rng), ReLU(), Linear(4, 1, rng)]
X = rng.normal(size=(5, 3))
y = rng.normal(size=(5, 1))

def net_loss():
    out = X
    for layer in layers:
        out = layer.forward(out)
    return np.mean((out - y) ** 2), out

loss, out = net_loss()
delta = 2 * (out - y) / len(X)           # derivative of the mean squared error
for layer in reversed(layers):
    delta = layer.backward(delta)

W = layers[0].W
numeric = np.zeros_like(W)
for i in range(W.shape[0]):
    for j in range(W.shape[1]):
        W[i, j] += 1e-5; lp = net_loss()[0]
        W[i, j] -= 2e-5; lm = net_loss()[0]
        W[i, j] += 1e-5
        numeric[i, j] = (lp - lm) / 2e-5

rel_error = np.abs(numeric - layers[0].dW).max() / np.abs(numeric).max()
print("dW shape:", layers[0].dW.shape, " relative error:", f"{rel_error:.1e}")

إشارة خاطئة، أو تبديل ناقص، أو نسيان القسمة على عدد الأمثلة: الكود يعمل، والشبكة تتدرب ببطء، أو لا تتدرب. بصمت.

لماذا الاتجاه العكسي بالذات؟

قاعدة السلسلة يمكن تطبيقها من البداية إلى النهاية أيضاً. لكن لدينا مخرج واحد، الخسارة، وملايين المدخلات، الأوزان.

البدء من الخسارة يعطي تدرّجها بالنسبة لكل شيء في مرور واحد، لأن كل تدرّج وسيط، مثل تدرّج h، يُحسب مرة واحدة ويستخدمه كل ما قبله.

reverse-mode automatic differentiation · autograd
سؤال مقابلة

سؤال قد تسمعه في المقابلة:

Explain backpropagation.

جواب قصير وجيد:

Backpropagation computes the gradient of the loss with respect to every parameter by applying the chain rule backwards through the computational graph. In the forward pass we compute and cache intermediate values. In the backward pass, each operation multiplies the upstream gradient by its local derivative and passes the result to its inputs. Gradients from multiple paths are summed. The cost is roughly the cost of a couple of forward passes, regardless of the number of parameters.

سؤال قد تسمعه في المقابلة:

Why not compute gradients numerically?

جواب قصير وجيد:

A numerical gradient needs about two forward passes per parameter, which is impossible for millions of parameters. It is also approximate. But it is very useful as a gradient check to test a hand-written backward pass on a small network.
