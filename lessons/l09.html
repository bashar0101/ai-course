بعد هذا الدرس ستعرف:
  • تفهم خوارزمية النزول بالتدرّج، وتكتبها في أربعة أسطر
  • تحسب خطوات نزول بيدك، وترى الخسارة تنقص
  • تفهم أثر معدل التعلّم: صغير جداً، ومناسب، وكبير جداً

الخوارزمية كلها في جملة

وصلنا إلى الفكرة التي تتعلّم بها كل النماذج تقريباً، من الانحدار الخطي إلى النماذج اللغوية الكبيرة:

احسب التدرّج، ثم حرّك كل معامل خطوة صغيرة عكسه. ثم كرر.

بالرموز، لكل معامل:

w←w−η ∂L∂w

السهم يعني: القيمة الجديدة تساوي.

والحرف اليوناني η يُقرأ "إيتا". هو معدل التعلّم: رقم صغير يحدد حجم الخطوة.

الاسم بالإنجليزية:

gradient descent · learning rate

لماذا علامة الطرح؟

من الدرس 6: المشتقة موجبة تعني أن الخسارة تصعد عندما يزيد المعامل.

إذن نريد أن ننقصه. وطرح رقم موجب ينقصه.

والمشتقة سالبة تعني العكس. وطرح رقم سالب يزيده.

علامة الطرح تعمل في الحالتين تلقائياً.

ولماذا نضرب في المشتقة نفسها، وليس في إشارتها فقط؟

لأن حجم المشتقة معلومة مفيدة.

بعيداً عن القاع، الأرض شديدة الانحدار، والمشتقة كبيرة: نأخذ خطوات كبيرة.

قرب القاع، الأرض مسطحة، والمشتقة صغيرة: نأخذ خطوات صغيرة ودقيقة.

الخوارزمية تبطئ وحدها عندما تقترب.

ثلاث حالات لمعدل التعلّم

في دالة الوعاء هذه بالذات، أي معدل أكبر من 1 يتباعد.

في المشاكل الحقيقية، لا نعرف الحد مسبقاً. نجرب قيماً مثل 0.1 و 0.01 و 0.001، ونراقب الخسارة.

كيف تعرف أن معدل التعلّم كبير؟

الخسارة تكبر بدل أن تنقص، أو تقفز صعوداً ونزولاً، أو تصبح قيمة غير رقمية.

أول ما تفعله: قسّم معدل التعلّم على عشرة، وجرب من جديد.

الخطوات التالية ستحسّن ببطء أكثر، حتى تصل إلى أفضل خط: ميل 1.5 وإزاحة 0.67 تقريباً.

بالكود

train_line.pyبايثون
import numpy as np

x = np.array([1, 2, 3])
y = np.array([2, 4, 5])

def mse(w, b):
    return np.mean((w * x + b - y) ** 2)

def grad(w, b):
    err = w * x + b - y
    return 2 * np.mean(err * x), 2 * np.mean(err)

w, b = 0.0, 0.0
lr = 0.1
history = []
for step in range(300):
    dw, db = grad(w, b)
    w -= lr * dw               # الخوارزمية كلها في هذين السطرين
    b -= lr * db
    history.append(mse(w, b))
    if step in (0, 1, 2, 10, 50, 299):
        print(f"step {step:3d}: w = {w:.4f}, b = {b:.4f}, loss = {history[-1]:.5f}")

compare_lr.pyبايثون
def train(lr, steps=30):
    w, b = 0.0, 0.0
    losses = []
    for _ in range(steps):
        dw, db = grad(w, b)
        w, b = w - lr * dw, b - lr * db
        losses.append(mse(w, b))
    return losses

plt.figure(figsize=(6, 3.4))
for lr in [0.01, 0.1, 0.19]:
    plt.plot(train(lr), lw=2, label=f"lr = {lr}")
plt.yscale("log")
plt.xlabel("step"); plt.ylabel("loss (log scale)")
plt.grid(True); plt.legend()
plt.show()

print("loss after 30 steps with lr=0.19:", f"{train(0.19)[-1]:.1f}")

سؤال مقابلة

سؤال قد تسمعه في المقابلة:

What happens if the learning rate is too large or too small?

جواب قصير وجيد:

If it is too small, training is very slow and may stop before reaching a good solution. If it is too large, each step jumps over the minimum, the loss goes up and down or grows, and training can diverge. We usually try values on a log scale, like 0.1, 0.01, 0.001, and watch the loss curve.

الخلاصة
  • النزول بالتدرّج: احسب التدرّج، وتحرك خطوة صغيرة عكسه، وكرر.
  • معدل التعلّم يحدد حجم الخطوة. صغير جداً بطيء، وكبير جداً يتباعد.
  • الخطوة تصغر وحدها قرب القاع، لأن المشتقة تصغر.
  • تدريب النموذج الخطي: التدرّج من الدرس 8، والتحديث من هذا الدرس.
  • راقب منحنى الخسارة دائماً. إذا كبرت الخسارة، صغّر معدل التعلّم.

الحل (افتحه بعد أن تحاول)

المشتقة L′(w)=2(w+1).

الخطوة الأولى: المشتقة 8، فالمعامل يصبح 3−0.25×8=1، والخسارة 4.

بايثون
def run(lr, w=3.0):
    steps = 0
    while abs(2 * (w + 1)) >= 1e-6:
        w -= lr * 2 * (w + 1)
        steps += 1
    return steps, w

print("lr=0.25:", run(0.25))
print("lr=0.5 :", run(0.5))

$$L(w) = (w + 1)^2$$

2. ابدأ من $w = 3$ بمعدل تعلّم 0.25. احسب خطوتين بيدك، واكتب الخسارة بعد كل خطوة.

المشتقة $L'(w) = 2(w + 1)$.

الخطوة الأولى: المشتقة 8، فالمعامل يصبح $3 - 0.25 \times 8 = 1$، والخسارة 4.
