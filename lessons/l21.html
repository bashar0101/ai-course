الطريقة الأولى: التجميع بالعينات

من الدرس السابق: الشجرة الواحدة غير مستقرة. تغيير صغير في البيانات يغيّرها كثيراً.

هذا عيب... لكنه هنا ميزة! لأنه يعطينا أشجاراً مختلفة بسهولة.

الخطوات:

  1. نسحب من البيانات عينة بنفس الحجم، مع الإرجاع: المثال الواحد قد يُسحب مرتين أو أكثر، وبعض الأمثلة لا تُسحب أبداً.
  2. ندرّب شجرة على هذه العينة.
  3. نكرر مئات المرات.
  4. للتوقع: تصويت الأشجار في التصنيف، أو متوسطها في الانحدار.

مثال على عينة بالإرجاع من خمسة أمثلة:

[A, B, C, D, E] → [B, B, D, A, E]

المثال C لم يُسحب، و B سُحب مرتين. في المتوسط، حوالي ثلث الأمثلة لا تدخل كل عينة.

الغابة العشوائية

الأشجار في التجميع بالعينات ما زالت متشابهة: إذا كانت ميزة قوية جداً، فكل الأشجار تبدأ بها.

الغابة العشوائية تضيف حيلة ثانية: عند كل سؤال، تختار الشجرة من مجموعة عشوائية صغيرة من الميزات فقط.

هكذا تُجبر الأشجار على التنوع، فتصبح أخطاؤها أقل ارتباطاً.

random forest

الغابة العشوائية من أقوى النماذج وأسهلها استخداماً: تعمل جيداً بدون ضبط كثير، ولا تحتاج توحيد مقياس.

الطريقة الثانية: التعزيز

فكرة مختلفة تماماً: بدل نماذج مستقلة، نبني النماذج واحداً بعد الآخر.

كل نموذج جديد يركّز على ما أخطأ فيه النموذج الحالي.

في الانحدار، الخطأ الذي بقي هو الباقي: الجواب ناقص التوقع الحالي.

التعزيز بالتدرّج يدرّب كل شجرة جديدة لتتوقع البواقي، ثم يضيف جزءاً من توقعها:

Fnew(x)=Fold(x)+η⋅tree(x)

الرقم η معدل تعلّم، مثل النزول بالتدرّج: خطوة صغيرة في كل جولة.

والأشجار هنا صغيرة جداً عادة: عمق واحد إلى ستة. كل شجرة ضعيفة وحدها، لكن مئات منها معاً قوية جداً.

boosting · gradient boosting

منحنى جيبي مع ضجيج. كل شجرة لها سؤال واحد فقط، لكن نجمع مئة منها:

boosting_scratch.pyبايثون
import numpy as np
import matplotlib.pyplot as plt
from sklearn.tree import DecisionTreeRegressor

rng = np.random.default_rng(0)
x = np.sort(rng.uniform(0, 6, 120))
y = np.sin(x) + rng.normal(0, 0.2, x.size)
X = x.reshape(-1, 1)

def boost(X, y, rounds, lr=0.3, depth=1):
    F = np.full(len(y), y.mean())
    trees = []
    for _ in range(rounds):
        residual = y - F
        t = DecisionTreeRegressor(max_depth=depth).fit(X, residual)   # الشجرة تتعلّم البواقي
        F = F + lr * t.predict(X)
        trees.append(t)
    return F, trees

plt.figure(figsize=(6, 3.6))
plt.scatter(x, y, s=12, color="gray", alpha=0.6, label="data")
for rounds in [1, 10, 100]:
    F, _ = boost(X, y, rounds)
    print(f"{rounds:3d} rounds: MSE = {np.mean((y - F) ** 2):.4f}")
    plt.plot(x, F, lw=2, label=f"{rounds} rounds")
plt.legend(); plt.grid(True)
plt.show()

from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import RandomForestClassifier, HistGradientBoostingClassifier

Xb, yb = load_breast_cancer(return_X_y=True)
X_tr, X_te, y_tr, y_te = train_test_split(Xb, yb, test_size=0.3, random_state=0, stratify=yb)

models = {
    "single tree":       DecisionTreeClassifier(random_state=0),
    "random forest":     RandomForestClassifier(n_estimators=300, random_state=0),
    "gradient boosting": HistGradientBoostingClassifier(random_state=0),
}
for name, m in models.items():
    m.fit(X_tr, y_tr)
    print(f"{name:18} test accuracy = {m.score(X_te, y_te):.3f}")

سؤال مقابلة

سؤال قد تسمعه في المقابلة:

What is the difference between bagging and boosting?

جواب قصير وجيد:

Bagging trains many models independently on bootstrap samples and averages them; it mainly reduces variance, like in random forests. Boosting trains models sequentially, each one fitting the errors of the current ensemble; it mainly reduces bias. Random forests are easy to tune; gradient boosting is often the most accurate on tabular data but needs more care with the learning rate and the number of trees.

الخلاصة
  • المجموعة تجمع نماذج كثيرة. تنفع عندما تخطئ النماذج بطرق مختلفة.
  • التجميع بالعينات: نماذج مستقلة على عينات بالإرجاع، ثم تصويت أو متوسط.
  • الغابة العشوائية: أشجار على عينات مختلفة، وميزات عشوائية عند كل سؤال.
  • التعزيز بالتدرّج: كل شجرة صغيرة تتعلّم بواقي ما قبلها، ونضيف جزءاً من توقعها.
  • للبيانات الجدولية: التعزيز غالباً الأقوى، والغابة الأسهل.

تمرين: الجولة الثالثة

في المثال المحلول، البواقي بعد جولتين: (−1,  0,  0,  1)، والتوقع الحالي (2,2,5,5).

  2. أي سؤال أو أسئلة هي الأفضل؟
  3. اختر السؤال x<1.5، وأضف نصف توقع الشجرة. ما الخسارة الجديدة؟
  4. تحقق بالكود بدالة التعزيز من الدرس، على نفس الأمثلة الأربعة، بثلاث جولات ومعدل 0.5.
تلميح

للسؤال الأول: الجهة الأولى فيها باقٍ واحد. الجهة الثانية فيها ثلاثة بواقي، متوسطها ثلث.

الحل (افتحه بعد أن تحاول)

السؤال x<1.5: الجهة الأولى (−1) مجموعها صفر. الثانية (0,0,1) متوسطها 1/3:

(13)2+(13)2+(23)2=69≈0.667

السؤال x<2.5: الجهتان (−1,0) و (0,1)، متوسطهما سالب نصف ونصف: المجموع 4×0.25=1.

السؤال x<3.5: مثل الأول بالتناظر: 0.667.

الأفضل: السؤال الأول أو الثالث، بالتساوي.

مع السؤال الأول: الشجرة تتوقع (−1,13,13,13). نضيف نصفها:

F3=(1.5,  2.167,  5.167,  5.167)MSE3=0.25+0.0278+0.0278+0.6944≈0.25

في المثال المحلول، البواقي بعد جولتين: $(-1,\; 0,\; 0,\; 1)$، والتوقع الحالي $(2, 2, 5, 5)$.

1. جرّب الأسئلة الثلاثة الممكنة: $x < 1.5$، و $x < 2.5$، و $x < 3.5$. لكل سؤال، احسب مجموع مربعات البواقي حول متوسط كل جهة.
2. أي سؤال أو أسئلة هي الأفضل؟
3. اختر السؤال $x < 1.5$، وأضف نصف توقع الشجرة. ما الخسارة الجديدة؟

السؤال $x < 1.5$: الجهة الأولى $(-1)$ مجموعها صفر. الثانية $(0, 0, 1)$ متوسطها $1/3$:

$$\left(\tfrac{1}{3}\right)^2 + \left(\tfrac{1}{3}\right)^2 + \left(\tfrac{2}{3}\right)^2 = \tfrac{6}{9} \approx 0.667$$

السؤال $x < 2.5$: الجهتان $(-1, 0)$ و $(0, 1)$، متوسطهما سالب نصف ونصف: المجموع $4 \times 0.25 = 1$.
السؤال $x < 3.5$: مثل الأول بالتناظر: 0.667.
الأفضل: السؤال الأول أو الثالث، بالتساوي.

مع السؤال الأول: الشجرة تتوقع $(-1, \tfrac13, \tfrac13, \tfrac13)$. نضيف نصفها:

$$F_3 = (1.5,\; 2.167,\; 5.167,\; 5.167) \qquad \text{MSE}_3 = \frac{0.25 + 0.0278 + 0.0278 + 0.694}{4} \approx 0.25$$
