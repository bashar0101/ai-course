لماذا أكثر من رأس؟

رأس انتباه واحد يعطي كل رمز متوسطاً موزوناً واحداً. أي نوعاً واحداً من العلاقات في كل مرة.

لكن الكلمة تحتاج علاقات كثيرة في نفس الوقت: من الفاعل؟ ما الكلمة السابقة مباشرة؟ إلى من يعود الضمير؟

الحل: عدة رؤوس صغيرة بالتوازي. لكل رأس مصفوفاته الخاصة، فيتعلّم نوعه الخاص من الانتباه.

ثم ندمج مخرجات الرؤوس، ونضربها في مصفوفة أخيرة تخلط المعلومات بينها.

الحيلة: نفس التكلفة

إذا كان طول التضمين dmodel، وعدد الرؤوس h، فكل رأس يعمل بطول أصغر:

dk=dmodelh

مثلاً 768 مع 12 رأساً: كل رأس بطول 64. والرؤوس المدموجة ترجع إلى 768.

ماذا تتعلّم الرؤوس؟

أبحاث تحليل النماذج المدربة وجدت رؤوساً متخصصة: رأس ينتبه دائماً للرمز السابق، ورأس يربط الضمير بما يعود إليه، ورأس ينسخ أنماطاً تكررت قبل ذلك في النص.

لم يبرمج أحد هذه التخصصات. ظهرت من التدريب وحده.

الانتباه لا يعرف الترتيب

انظر إلى صيغة الانتباه مرة أخرى: ضرب نقطي بين كل رمزين، ثم متوسط موزون. لا يوجد أي شيء عن موضع الرمز.

إذا بدّلنا ترتيب الكلمات، تتبدل المخرجات بنفس الترتيب، ولا يتغير أي رقم آخر.

permutation equivariance

أي أن "الكلب عضّ الرجل" و"الرجل عضّ الكلب" متطابقتان للانتباه! كيس كلمات، بلا ترتيب. سنتحقق من هذا في الكود.

الترميز الجيبي: ساعات بسرعات مختلفة

لكل زوج من الأبعاد، نختار سرعة دوران ωi، ونضع جيب وجيب تمام زاوية الموضع:

PE(pos,2i)=sin⁡(pos⋅ωi),PE(pos,2i+1)=cos⁡(pos⋅ωi),ωi=1100002i/d

كل زوج مثل عقرب ساعة يدور. الأزواج الأولى تدور بسرعة، والأخيرة ببطء شديد. مثل عقارب الثواني والدقائق والساعات: معاً تحدد كل لحظة بشكل فريد.

الترميز الدوراني

فكرة أحدث وأذكى: بدل إضافة متجه الموضع للتضمين، ندوّر الاستعلام والمفتاح داخل الانتباه، بزاوية تتناسب مع الموضع.

كل زوج من الأبعاد يُدوَّر كنقطة في مستوى، بسرعته الخاصة، مثل الساعات أعلاه.

والنتيجة الجميلة: الضرب النقطي بين استعلام في الموضع m ومفتاح في الموضع n يعتمد فقط على الفرق n−m.

أي أن الانتباه يرى المسافة بين الرمزين، لا موضعيهما المطلقين. "الكلمة التي قبلي بثلاث كلمات" لها نفس المعنى في أول النص وفي آخره.

الانتباه متعدد الرؤوس

multi_head.pyبايثون
import math
import numpy as np
import torch
import torch.nn.functional as F
from torch import nn

class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, n_heads):
        super().__init__()
        assert d_model % n_heads == 0
        self.h, self.d_k = n_heads, d_model // n_heads
        self.qkv = nn.Linear(d_model, 3 * d_model)      # W_Q, W_K, W_V in one matrix
        self.out = nn.Linear(d_model, d_model)          # W_O

    def forward(self, x, causal=True):
        B, n, d = x.shape
        q, k, v = self.qkv(x).split(d, dim=-1)          # each (B, n, d)
        # split into heads: (B, n, d) -> (B, h, n, d_k)
        q, k, v = (t.view(B, n, self.h, self.d_k).transpose(1, 2) for t in (q, k, v))
        y = F.scaled_dot_product_attention(q, k, v, is_causal=causal)   # (B, h, n, d_k)
        y = y.transpose(1, 2).reshape(B, n, d)          # merge heads back
        return self.out(y)

torch.manual_seed(0)
mha = MultiHeadAttention(d_model=768, n_heads=12)
x = torch.randn(2, 10, 768)
print("output shape:", tuple(mha(x).shape))
print("parameters  :", sum(p.numel() for p in mha.parameters()))
ref = nn.MultiheadAttention(embed_dim=768, num_heads=12)
print("PyTorch's own layer:", sum(p.numel() for p in ref.parameters()))

sinusoidal.pyبايثون
def sinusoidal(n_positions, d):
    pos = np.arange(n_positions)[:, None]                 # (n, 1)
    omega = 1 / 10000 ** (np.arange(0, d, 2) / d)         # (d/2,)
    pe = np.zeros((n_positions, d))
    pe[:, 0::2] = np.sin(pos * omega)                      # even dimensions
    pe[:, 1::2] = np.cos(pos * omega)                      # odd dimensions
    return pe

print(sinusoidal(3, 4).round(3))

الترميز الدوراني: المسافة فقط

ندوّر زوج أبعاد واحداً، ونقارن ضربين نقطيين بنفس المسافة بين الموضعين، في مكانين مختلفين من النص:

rope.pyبايثون
def rotate(v, position, theta=0.1):
    a = position * theta
    R = np.array([[np.cos(a), -np.sin(a)], [np.sin(a), np.cos(a)]])
    return R @ v

q, k = np.array([1.0, 2.0]), np.array([0.5, -1.0])
near_start = rotate(q, 3) @ rotate(k, 1)          # positions 3 and 1: distance 2
far_away = rotate(q, 503) @ rotate(k, 501)        # positions 503 and 501: distance 2
other = rotate(q, 3) @ rotate(k, 0)               # distance 3
print(round(near_start, 6), round(far_away, 6), round(other, 6))

تقسيم الرؤوس بالشكل الخاطئ

إعادة التشكيل من (B,n,d) إلى (B,h,n,dk) تحتاج خطوتين: تقسيم البعد الأخير، ثم تبديل البعدين. تقسيم مباشر إلى الشكل النهائي يخلط أرقام رموز مختلفة في نفس الرأس.

الكود يعمل، والأشكال صحيحة، والنتائج خاطئة بصمت. اختبر دائماً: رأس واحد يجب أن يعطي نتيجة الانتباه العادي.

سؤال مقابلة

سؤال قد تسمعه في المقابلة:

Why does the transformer use multi-head attention?

جواب قصير وجيد:

A single attention head produces one weighted average per token, so it can express only one kind of relation at a time. Multiple heads, each with its own projections into a smaller subspace, run in parallel and can attend to different things, such as syntax, previous tokens or coreference. Their outputs are concatenated and mixed by an output projection. Because each head works in d_model / h dimensions, the cost is similar to a single full-size head.

سؤال قد تسمعه في المقابلة:

Why do transformers need positional encodings?

جواب قصير وجيد:

Self-attention is permutation-equivariant: it treats the input as a set, so without extra information the model cannot distinguish word orders. Positional encodings inject position information, either by adding learned or sinusoidal vectors to the embeddings, or by rotating queries and keys as in RoPE.

سؤال قد تسمعه في المقابلة:

What is the advantage of rotary positional embeddings?

جواب قصير وجيد:

RoPE rotates queries and keys by angles proportional to their positions, so their dot product depends only on the relative distance between tokens. This gives relative position awareness directly inside attention and tends to extrapolate better to longer contexts than learned absolute positions.

الخلاصة
  • عدة رؤوس صغيرة بالتوازي، كل رأس يتعلّم نوعاً من العلاقات. ثم دمج، ثم إسقاط مخرج.
  • كل رأس بطول dmodel/h، فالتكلفة مثل رأس واحد كبير. والمعاملات 4dmodel2 تقريباً، مهما كان عدد الرؤوس.
  • الانتباه وحده لا يعرف الترتيب: تبديل المدخلات يبدّل المخرجات فقط.
  • نضيف الموضع: مواضع متعلّمة، أو جيبية، أو دورانية.
  • الجيبية: ساعات بسرعات مختلفة. والدورانية: الانتباه يرى المسافة بين الرموز.
