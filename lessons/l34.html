من الدماغ، باختصار شديد

الخلية العصبية في الدماغ تستقبل إشارات من خلايا أخرى. بعض الإشارات تثيرها، وبعضها يثبطها.

إذا تجاوز مجموع الإثارة حداً معيناً، تطلق الخلية إشارة إلى الخلايا التالية.

العصبون الاصطناعي فكرة مبسطة جداً من هذا. لا تأخذ التشبيه بجدية كبيرة:

الشبكات العصبية الحديثة رياضيات، وليست نسخة من الدماغ.

العصبون الاصطناعي

ثلاث خطوات، تعرف الأوليين جيداً:

  1. اضرب كل مدخل في وزنه، واجمع. هذا الضرب النقطي من الدرس 4.
  2. أضف الإزاحة.
  3. طبّق دالة تفعيل على الناتج.
z=w1x1+w2x2+⋯+wnxn+b=w⋅x+b
a=g(z)

الحرف g هو دالة التفعيل، و a هو مخرج العصبون.

artificial neuron · activation function

لماذا دالة التفعيل؟

بدونها، العصبون مجموع موزون فقط: دالة خطية.

وسنرى في الدرس القادم أن طبقات كثيرة من دوال خطية تبقى دالة خطية واحدة. لا فائدة من العمق!

دالة التفعيل تضيف الانحناء. وهي التي تجعل الشبكات قادرة على تعلّم أشكال معقدة.

activations.pyبايثون
import numpy as np
import matplotlib.pyplot as plt

z = np.linspace(-4, 4, 400)
fig, axes = plt.subplots(1, 4, figsize=(11, 2.6), sharey=True)
funcs = [("step", (z >= 0).astype(float)), ("sigmoid", 1 / (1 + np.exp(-z))),
         ("tanh", np.tanh(z)), ("ReLU", np.maximum(0, z))]
for ax, (name, v) in zip(axes, funcs):
    ax.plot(z, v, lw=2.5)
    ax.axhline(0, color="gray", lw=0.8); ax.axvline(0, color="gray", lw=0.8)
    ax.set_title(name); ax.set_ylim(-1.3, 2.5); ax.grid(True)
plt.tight_layout()
plt.show()

لماذا ريلو هي الأشهر اليوم؟

  • سريعة جداً: مقارنة واحدة بالصفر، بدون أسّ.
  • مشتقتها 1 للموجب: التدرّج يمر كما هو، ولا يضعف. أما السيغمويد، فأكبر مشتقة لها ربع: عبر عشر طبقات يتضاءل التدرّج كثيراً. تذكّر الدرس 13.
  • العيب: إذا بقي مجموع العصبون سالباً دائماً، فمشتقته صفر دائماً، فلا يتعلّم أبداً. عصبون "ميت".

العصبون الواحد يقسم المستوى بخط مستقيم: جهة واحد، وجهة صفر. هذا حد القرار الخطي من الدرس 18.

ارسم النقاط الأربع: الواحدات في زاويتين متقابلتين، والأصفار في الزاويتين الأخريين. لا يوجد خط واحد يفصلها.

هذه الملاحظة البسيطة أوقفت أبحاث الشبكات العصبية سنوات طويلة في السبعينيات.

الحل: عصبونات أكثر، في طبقات. عصبونان يرسمان خطين، وعصبون ثالث يجمعهما. هذا موضوع الدرس القادم.

neuron.pyبايثون
import numpy as np

def relu(z):
    return np.maximum(0, z)

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def step(z):
    return (z >= 0).astype(float)

def neuron(x, w, b, activation):
    z = x @ w + b
    return activation(z)

x = np.array([2.0, 1.0])
w = np.array([0.5, -1.0])
for f in [relu, sigmoid, np.tanh, step]:
    print(f"{f.__name__:8}: {neuron(x, w, 0.2, f):.3f}")

محاولة يائسة: "إما أو" بعصبون واحد

نجرب مئة ألف تركيبة عشوائية من الأوزان والإزاحة، ونعدّ أفضل نتيجة:

xor_search.pyبايثون
rng = np.random.default_rng(0)
target = np.array([0, 1, 1, 0])
best = 0
for _ in range(100_000):
    w = rng.uniform(-5, 5, 2)
    b = rng.uniform(-5, 5)
    correct = np.sum(neuron(X, w, b, step) == target)
    best = max(best, correct)
print("best result for XOR with one neuron:", best, "of 4")

سؤال مقابلة

سؤال قد تسمعه في المقابلة:

Why do neural networks need non-linear activation functions?

جواب قصير وجيد:

Without them, every layer is a linear function, and a composition of linear functions is still one linear function. So a deep network would be no more powerful than a single linear model. Non-linear activations like ReLU let stacked layers represent curved decision boundaries and complex functions. ReLU is popular because it is cheap and its gradient is 1 for positive inputs.

الخلاصة
  • العصبون: ضرب نقطي، وإزاحة، ثم دالة تفعيل.
  • دالة التفعيل تضيف الانحناء. بدونها، الطبقات لا تضيف شيئاً.
  • ريلو الأشهر: سريعة، ومشتقتها 1 للموجب.
  • عصبون بسيغمويد هو الانحدار اللوجستي.
  • العصبون الواحد يرسم حداً خطياً فقط، فيعجز عن "إما أو". نحتاج طبقات.
