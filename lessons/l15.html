أول خوارزمية: أقرب الجيران

الفكرة من المثل المعروف: قل لي من أصدقاؤك، أقل لك من أنت.

لكي نصنّف مثالاً جديداً:

  1. نحسب المسافة بينه وبين كل مثال في بيانات التدريب.
  2. نأخذ أقرب K أمثلة. هؤلاء الجيران.
  3. في التصنيف: الجيران يصوّتون، والفئة الأكثر تفوز.
  4. في الانحدار: نأخذ متوسط أجوبة الجيران.

لاحظ شيئاً غريباً: لا يوجد تدريب حقيقي! الخوارزمية تحفظ البيانات فقط.

كل العمل يحدث وقت التوقع. لذلك اسمها بالإنجليزية:

k-nearest neighbors (KNN)

والرقم K نختاره نحن قبل التدريب. هذا النوع من الأرقام اسمه معامل فائق، لأن النموذج لا يتعلّمه من البيانات.

knn_scratch.pyبايثون
import numpy as np

X_train = np.array([[1, 0], [4, 0], [3, 1], [5, 5], [5, 2], [6, 3]])
y_train = np.array([0, 0, 0, 1, 1, 1])      # 0 رسب، 1 نجح

def knn_predict(x_new, k):
    distances = np.linalg.norm(X_train - x_new, axis=1)   # مسافة لكل صف
    nearest = np.argsort(distances)[:k]                   # أرقام أقرب k
    votes = y_train[nearest]
    return np.bincount(votes).argmax()                    # الفئة الأكثر

for k in [1, 3, 5]:
    print(f"k = {k}: prediction = {knn_predict(np.array([3, 3]), k)}")
الناتج

k = 3: prediction = 1
k = 5: prediction = 1

from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

raw = KNeighborsClassifier(n_neighbors=5).fit(X_tr, y_tr)

الخط الذي يربط التوحيد بالنموذج اسمه خط المعالجة:

Pipeline

فائدته الكبيرة: يحسب إحصاءات التوحيد من بيانات التدريب وحدها، ثم يطبقها على الاختبار. بدون تسريب.

أثر عدد الجيران

k_effect.pyبايثون
import matplotlib.pyplot as plt

ks = range(1, 41)
train_acc, test_acc = [], []
for k in ks:
    m = make_pipeline(StandardScaler(), KNeighborsClassifier(n_neighbors=k)).fit(X_tr, y_tr)
    train_acc.append(m.score(X_tr, y_tr))
    test_acc.append(m.score(X_te, y_te))

plt.figure(figsize=(6, 3.4))
plt.plot(ks, train_acc, lw=2, label="train accuracy")
plt.plot(ks, test_acc, lw=2, label="test accuracy")
plt.xlabel("k (number of neighbors)"); plt.ylabel("accuracy")
plt.legend(); plt.grid(True)
plt.show()

هذا مثال واضح على الطالب الذي حفظ الأجوبة. دقة الاختبار هي التي تقول الحقيقة.

سؤال مقابلة

سؤال قد تسمعه في المقابلة:

How does k-nearest neighbors work, and what is its main weakness?

جواب قصير وجيد:

To predict a new point, it computes the distance to every training example, takes the k closest ones, and uses a majority vote for classification or the average for regression. There is no real training. Its weaknesses: prediction is slow on big datasets, it needs feature scaling, and it works badly with many features because distances lose their meaning.

الخلاصة
  • مثال، وميزة، وتسمية، ومجموعة تدريب، ومجموعة اختبار: كلمات كل مشروع.
  • نقيس الأداء على بيانات لم يرها النموذج. دقة التدريب وحدها تخدع.
  • أقرب الجيران: احسب المسافات، وخذ الأقرب، ودعهم يصوّتون.
  • عدد الجيران معامل فائق نختاره نحن. قليل جداً يتأثر بالضجيج، وكثير جداً يفقد التفاصيل.
  • التوحيد القياسي ضروري لكل خوارزمية تعتمد على المسافة. واستخدم خط المعالجة لتطبيقه بدون تسريب.
