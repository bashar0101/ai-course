self-attention
الانتباه متوسط موزون. كل الذكاء في طريقة حساب الأوزان.

ثلاثة أدوار: الاستعلام، والمفتاح، والقيمة

فكّر في قاموس بايثون: تعطيه مفتاحاً، فيبحث عن المفتاح المطابق تماماً، ويرجع قيمته.

الانتباه قاموس ناعم: لا يبحث عن تطابق تام، بل يقيس تشابه الاستعلام مع كل المفاتيح، ويرجع خليطاً من كل القيم، بنسب التشابه.

كل رمز يصنع ثلاثة متجهات من تضمينه:

  • الاستعلام: ماذا أبحث عنه؟ مثلاً الضمير: "أبحث عن اسم مذكّر قبلي".
  • المفتاح: كيف أعرّف نفسي؟ مثلاً الكتاب: "أنا اسم مذكّر".
  • القيمة: ماذا أعطي من ينتبه إليّ؟ معلومات الكتاب نفسها.
query · key · value

والثلاثة تأتي من ضرب التضمين في ثلاث مصفوفات يتعلّمها النموذج:

Q=XWQ,K=XWK,V=XWV

الأمثلة عن الضمير والمذكّر للتوضيح فقط. النموذج لا يعرف هذه الكلمات. هو يتعلّم المصفوفات الثلاث بالنزول بالتدرّج، وقد يجد أنماطاً لا اسم لها عندنا.

القناع السببي

النموذج اللغوي يتدرب على توقع الرمز التالي في كل موضع دفعة واحدة. لو رأى الرمز الموضع الذي بعده، لنسخ الجواب ببساطة.

لذلك نمنع كل رمز من الانتباه إلى ما بعده: درجات المستقبل تصبح سالب لا نهاية، فأوزانها صفر.

causal mask

مصفوفة الأوزان تصبح مثلثاً سفلياً: الصف الأول يرى رمزاً واحداً، والثاني رمزين، والأخير يرى الكل.

مصفوفة الأوزان n×n: كل رمز مع كل رمز. نص من ألف رمز يعطي مليون درجة. ونص من 8192 رمزاً يعطي أكثر من 67 مليوناً، في كل طبقة!

O(n²)

لكن مقابل ذلك: كل المواضع تُحسب معاً، بالتوازي، بضرب مصفوفات. بلا انتظار خطوة بعد خطوة كما في الشبكات التكرارية. وكل رمز يصل إلى أي رمز قبله في خطوة واحدة، مهما كانت المسافة.

attention_numpy.pyبايثون
import numpy as np
import torch
import torch.nn.functional as F
from torch import nn

def softmax(x):
    e = np.exp(x - x.max(axis=-1, keepdims=True))
    return e / e.sum(axis=-1, keepdims=True)

def attention(Q, K, V, causal=False):
    scores = Q @ K.T / np.sqrt(K.shape[-1])            # (n, n)
    if causal:
        future = np.triu(np.ones_like(scores, dtype=bool), k=1)
        scores = np.where(future, -np.inf, scores)      # hide the future
    weights = softmax(scores)                           # each row sums to 1
    return weights @ V, weights

Q = np.array([[1, 0, 1, 0], [0, 2, 0, 2], [2, 0, 2, 0]], dtype=float)
K = np.array([[1, 0, 1, 0], [0, 1, 0, 1], [1, 1, 0, 0]], dtype=float)
V = np.array([[1, 0], [0, 1], [1, 1]], dtype=float)

out, w = attention(Q, K, V)
print("weights:\n", w.round(3), "\noutput:\n", out.round(3))
out_c, w_c = attention(Q, K, V, causal=True)
print("causal weights:\n", w_c.round(3), "\ncausal output:\n", out_c.round(3))

self_attention.pyبايثون
class SelfAttention(nn.Module):
    def __init__(self, d_model, d_k):
        super().__init__()
        self.W_q = nn.Linear(d_model, d_k, bias=False)
        self.W_k = nn.Linear(d_model, d_k, bias=False)
        self.W_v = nn.Linear(d_model, d_k, bias=False)

    def forward(self, x):                                   # x: (batch, n, d_model)
        q, k, v = self.W_q(x), self.W_k(x), self.W_v(x)     # (batch, n, d_k)
        scores = q @ k.transpose(-2, -1) / k.shape[-1] ** 0.5    # (batch, n, n)
        n = x.shape[1]
        future = torch.triu(torch.ones(n, n, dtype=torch.bool), diagonal=1)
        scores = scores.masked_fill(future, float("-inf"))
        weights = scores.softmax(dim=-1)
        return weights @ v, weights

torch.manual_seed(0)
layer = SelfAttention(d_model=8, d_k=8)
x = torch.randn(2, 5, 8)                     # 2 sentences, 5 tokens, 8 numbers each
y, weights = layer(x)
print("output:", tuple(y.shape), " weights:", tuple(weights.shape))
print("first sentence weights:\n", weights[0].detach().numpy().round(2))
print("parameters:", sum(p.numel() for p in layer.parameters()))

أثر القسمة على الجذر

نولّد استعلامات ومفاتيح عشوائية بأطوال مختلفة، ونقيس انتشار الدرجات، وأكبر وزن بعد السوفتماكس:

why_scale.pyبايثون
rng = np.random.default_rng(0)
for d in [4, 64, 512]:
    q = rng.normal(size=(1000, d))
    k = rng.normal(size=(1000, 10, d))                   # 10 keys per query
    raw = np.einsum("nd,nkd->nk", q, k)
    top_raw = softmax(raw).max(axis=1).mean()
    top_scaled = softmax(raw / np.sqrt(d)).max(axis=1).mean()
    print(f"d = {d:3}: score std {raw.std():5.1f} | top weight without scaling {top_raw:.2f}, "
          f"with scaling {top_scaled:.2f}")

نسيان القناع في نموذج يولّد النص

بدون القناع، التدريب يبدو ممتازاً: الخسارة تنزل إلى قرب الصفر بسرعة! لأن كل موضع يرى الجواب الذي بعده وينسخه.

سؤال مقابلة

سؤال قد تسمعه في المقابلة:

Explain scaled dot-product attention.

جواب قصير وجيد:

Each token is projected into a query, a key and a value. The attention scores are the dot products between each query and all keys, divided by the square root of the key dimension. A softmax over each row turns the scores into weights that sum to one, and the output for each token is the weighted sum of the value vectors. It is a soft dictionary lookup where the query is matched against all keys.

سؤال قد تسمعه في المقابلة:

Why divide by the square root of d_k?

جواب قصير وجيد:

For random vectors, the variance of a dot product grows linearly with the dimension, so the scores become large for big d_k. Large scores push the softmax into saturation, where it is nearly one-hot and its gradients are tiny. Dividing by sqrt(d_k) keeps the scores at unit scale.

سؤال قد تسمعه في المقابلة:

What is the causal mask and why is it needed?

جواب قصير وجيد:

In an autoregressive language model, each position is trained to predict the next token, so it must not attend to later positions. The mask sets the scores for future positions to minus infinity before the softmax, making their weights zero. Without it the model would simply copy the answer during training.

سؤال قد تسمعه في المقابلة:

What is the computational complexity of self-attention?

جواب قصير وجيد:

Quadratic in the sequence length: every token attends to every other token, so the score matrix is n by n, with O(n² · d) time and O(n²) memory for the weights.
