من خط إلى مصنّف

نريد أن نتوقع شيئاً له جوابان: هل سينجح الطالب؟ هل الرسالة مزعجة؟ هل الورم خبيث؟

نسمي أحد الجوابين 1، والآخر 0.

الانحدار الخطي يعطي أي رقم. لكننا نريد احتمال أن الجواب 1.

عندنا كل الأدوات من الدرس 13:

  1. نحسب درجة خطية، كما في الانحدار الخطي:
z=w⋅x+b
  1. نحوّلها إلى احتمال بالسيغمويد:
p=σ(z)=11+e−z
  1. نقرر: إذا كان الاحتمال نصفاً أو أكثر، نتوقع 1. وإلا 0.

هذا كل النموذج. اسمه الانحدار اللوجستي.

logistic regression

الاسم مضلل قليلاً: هو مصنّف، وليس انحداراً. الاسم تاريخي.

حد القرار

متى يكون الاحتمال نصفاً بالضبط؟ السيغمويد تساوي نصفاً عندما تكون الدرجة صفراً:

w⋅x+b=0

هذه معادلة خط مستقيم في فضاء الميزات. مع ميزتين:

w1x1+w2x2+b=0

على جهة من الخط نتوقع 1، وعلى الجهة الأخرى نتوقع 0.

لذلك الانحدار اللوجستي مصنّف خطي: يفصل بين الفئتين بخط مستقيم، أو بمستوى مع ميزات أكثر.

decision boundary

وكلما ابتعدت النقطة عن الخط، كبرت الدرجة، واقترب الاحتمال من 0 أو 1.

النقاط قرب الخط احتمالها قرب النصف: النموذج غير متأكد منها.

الخسارة: الإنتروبيا المتقاطعة الثنائية

من الدرس 14، الخسارة الصحيحة للاحتمالات هي سالب لوغاريتم احتمال الجواب الصحيح:

L=−1n∑i[ yiln⁡pi+(1−yi)ln⁡(1−pi) ]

لماذا ليس متوسط مربعات الأخطاء؟ لأن مع السيغمويد، مربعات الأخطاء تعطي أرضاً فيها مناطق مسطحة جداً.

النموذج الواثق من جواب خاطئ يأخذ تدرّجاً صغيراً جداً، فيتعلّم ببطء.

الإنتروبيا المتقاطعة تعاقبه بقوة، وتدرّجها كبير في هذه الحالة بالضبط.

التدرّج: مفاجأة جميلة

نطبق قاعدة السلسلة على الطريق: من الخسارة إلى الاحتمال، ثم إلى الدرجة، ثم إلى الوزن.

بعد التبسيط، يختفي كل شيء تقريباً، ويبقى:

∂L∂w=1n∑i(pi−yi) xi∂L∂b=1n∑i(pi−yi)
نفس شكل الانحدار الخطي تماماً: الخطأ مضروباً في المدخل. فقط الخطأ الآن هو الاحتمال ناقص الجواب.
الاشتقاق خطوة خطوة

لمثال واحد، نكتب ثلاث مشتقات محلية.

الخسارة بالنسبة للاحتمال:

∂L∂p=−yp+1−y1−p

الاحتمال بالنسبة للدرجة، من الدرس 13:

∂p∂z=p(1−p)

الدرجة بالنسبة للوزن:

∂z∂w=x

نضرب الثلاثة، بقاعدة السلسلة:

(−yp+1−y1−p)p(1−p) x=(−y(1−p)+(1−y)p) x=(p−y) x

الحد p(1−p) ألغى المقامين. لهذا السبب بالذات تتناسب السيغمويد مع الإنتروبيا المتقاطعة: التدرّج لا يضعف أبداً عندما يخطئ النموذج بثقة.

logreg_scratch.pyبايثون
def sigmoid(z):
    return 1 / (1 + np.exp(-z))

class LogisticRegressionGD:
    def __init__(self, lr=0.1, epochs=2000):
        self.lr, self.epochs = lr, epochs

    def fit(self, X, y):
        self.w = np.zeros(X.shape[1])
        self.b = 0.0
        self.history = []
        for _ in range(self.epochs):
            p = self.predict_proba(X)
            err = p - y                               # الاحتمال ناقص الجواب
            self.w -= self.lr * X.T @ err / len(y)
            self.b -= self.lr * err.mean()
            eps = 1e-12
            self.history.append(-np.mean(y * np.log(p + eps) + (1 - y) * np.log(1 - p + eps)))
        return self

    def predict_proba(self, X):
        return sigmoid(X @ self.w + self.b)

    def predict(self, X):
        return (self.predict_proba(X) >= 0.5).astype(int)

clf = LogisticRegressionGD().fit(X, y)
print("w =", clf.w.round(3), " b =", round(clf.b, 3))
print("first loss:", round(clf.history[0], 3), " last loss:", round(clf.history[-1], 3))
print("training accuracy:", np.mean(clf.predict(X) == y))

سؤال مقابلة

سؤال قد تسمعه في المقابلة:

Why is logistic regression called a linear classifier?

جواب قصير وجيد:

Because it predicts class 1 when the linear score w·x + b is positive. The decision boundary, where the probability is 0.5, is the set of points where w·x + b = 0, which is a straight line or a flat plane. The sigmoid only turns the score into a probability; it does not bend the boundary.

الخلاصة
  • الانحدار اللوجستي: درجة خطية، ثم سيغمويد، ثم عتبة.
  • حد القرار حيث الدرجة صفر: خط مستقيم. لذلك هو مصنّف خطي.
  • الخسارة: الإنتروبيا المتقاطعة الثنائية.
  • التدرّج: الاحتمال ناقص الجواب، مضروباً في المدخل. نفس شكل الانحدار الخطي.
  • لفئات كثيرة: درجة لكل فئة، ثم سوفتماكس. هذه آخر طبقة في شبكات التصنيف.

الأخطاء $(0.5, -0.5)$. التدرّج:

$$\frac{\partial L}{\partial w} = \frac{0.5 \times 1 + (-0.5) \times 3}{2} = -0.5 \qquad \frac{\partial L}{\partial b} = \frac{0.5 - 0.5}{2} = 0$$

بعد الخطوة: الوزن $0 - 0.5 \times (-0.5) = 0.25$، والإزاحة صفر.
