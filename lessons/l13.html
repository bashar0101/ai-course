سوفتماكس: قائمة درجات إلى توزيع

لعدة فئات، عندنا درجة لكل فئة. سوفتماكس تعمل خطوتين:

  1. ترفع e إلى أس كل درجة: كل شيء يصبح موجباً.
  2. تقسم كل ناتج على المجموع: المجموع يصبح واحداً.
pi=ezi∑jezj

الدرجة الأكبر تأخذ الاحتمال الأكبر، والترتيب لا يتغير.

لكن الفرق يُضخَّم: بسبب الأسّ، الفرق بين درجتين يصبح نسبة بين احتمالين.

سوفتماكس في آخر كل مصنّف

كل مصنّف لعدة فئات تقريباً ينتهي بسوفتماكس. وكذلك النموذج اللغوي الكبير:

آخر طبقة تعطي درجة لكل كلمة في القاموس، ثم سوفتماكس، فيصبح عندنا احتمال لكل كلمة تالية.

الحرارة

قبل سوفتماكس، نستطيع أن نقسم كل الدرجات على رقم T اسمه الحرارة:

pi=ezi/T∑jezj/T
  • حرارة صغيرة، أقل من 1: الفروق تكبر. الفئة الأعلى تأخذ تقريباً كل شيء.
  • حرارة 1: سوفتماكس العادية.
  • حرارة كبيرة: الفروق تصغر. الاحتمالات تتقارب.

عندما تغيّر إعداد الحرارة في نموذج لغوي، هذا بالضبط ما يحدث. سنعود إليه في الدرس 50.

الاستقرار العددي: لا تدع الأرقام تنفجر

الدالة الأسية تكبر بسرعة هائلة.

أكبر أس يستطيع الجهاز حسابه بالأرقام العادية حوالي 709. بعده يصبح الناتج لانهاية.

ودرجات مثل 1000 تحدث فعلاً في النماذج الكبيرة.

الحل حيلة بسيطة: اطرح أكبر درجة من كل الدرجات قبل الأسّ.

ezi−m∑jezj−m=ezi e−m∑jezj e−m=ezi∑jezj

الرقم e−m يظهر فوق وتحت، فيختفي. النتيجة نفسها تماماً.

لكن الآن أكبر درجة صفر، وأكبر أسّ يساوي 1. لا انفجار أبداً.

بالكود

softmax.pyبايثون
import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def softmax_naive(z):
    e = np.exp(z)
    return e / e.sum()

def softmax(z, T=1.0):
    z = np.asarray(z, dtype=float) / T
    e = np.exp(z - z.max())           # الحيلة: اطرح الأكبر
    return e / e.sum()

print("sigmoid:", sigmoid(np.array([-2, 0, 2])).round(3))
print("softmax:", softmax([2, 1, 0.1]).round(3))
print("T = 0.5:", softmax([2, 1, 0.1], T=0.5).round(3))
print("T = 2  :", softmax([2, 1, 0.1], T=2).round(3))

مشتقة السيغمويد: شكل جميل سنحتاجه

مشتقة السيغمويد تُكتب بالسيغمويد نفسها:

σ′(z)=σ(z) (1−σ(z))

عند الصفر: 0.5×0.5=0.25. وهذه أكبر قيمة ممكنة للمشتقة.

وبعيداً عن الصفر تقترب من الصفر. تذكّر هذا: في الدرس 42 سنرى كيف يسبب مشكلة في الشبكات العميقة.

بايثون
def numeric_derivative(f, z, h=1e-5):
    return (f(z + h) - f(z - h)) / (2 * h)

for z in [0.0, 2.0, 5.0]:
    rule = sigmoid(z) * (1 - sigmoid(z))
    print(f"z = {z}: rule = {rule:.5f}, numeric = {numeric_derivative(sigmoid, z):.5f}")

سؤال مقابلة

سؤال قد تسمعه في المقابلة:

What does softmax do, and why do we subtract the maximum before computing it?

جواب قصير وجيد:

Softmax turns a vector of raw scores into probabilities: it takes the exponential of each score and divides by the sum, so all values are positive and add up to one. We subtract the maximum score first because exponentials of large numbers overflow. Subtracting a constant does not change the result, since it cancels in the numerator and denominator.
