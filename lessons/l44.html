المشكلة: الأرقام وحدها لا تكفي

المقطّع أعطى كل رمز رقماً. لكن الرقم مجرد عنوان في قائمة.

لو كان "قط" الرقم 5، و"كلب" الرقم 6، و"سيارة" الرقم 7، فهذا لا يعني أن الكلب أقرب إلى السيارة من القط.

المتجه الأحادي

فكرة أولى: كل رمز متجه طوله عدد المفردات، كله أصفار إلا واحداً في مكان الرمز.

one-hot vector

هكذا لا يوجد ترتيب مزيف. لكن مشكلتان:

  • ضخم: مع خمسين ألف رمز، كل متجه فيه خمسون ألف رقم.
  • كل الكلمات متساوية البعد: الضرب النقطي بين أي متجهين أحاديين مختلفين صفر. "قط" بعيدة عن "كلب" بقدر بعدها عن "سيارة".

من أين يأتي المعنى؟

فكرة من علم اللغة، عمرها أكثر من ستين عاماً: تعرف الكلمة من رفاقها.

الكلمات التي تظهر في سياقات متشابهة لها معانٍ متشابهة.

distributional hypothesis

"شربت ... ساخنة في الصباح". ما الكلمة الناقصة؟ قهوة، أو شاي. الكلمتان تظهران في نفس السياقات، فهما متشابهتان.

طريقتان لتحويل هذه الفكرة إلى متجهات:

  1. بالتنبؤ: درّب شبكة تتوقع الكلمات المجاورة من الكلمة. التضمينات التي تتعلّمها تحمل المعنى. هذه فكرة نموذج مشهور من 2013.
  2. بالعدّ: عدّ كم مرة تظهر كل كلمتين متجاورتين، ثم اضغط الجدول الضخم إلى متجهات قصيرة.
word2vec · count-based embeddings

وفي النماذج اللغوية، التضمين جزء من النموذج نفسه: يتعلّم مع كل الأوزان الأخرى، وهو يتوقع الرمز التالي. نرى هذا في الدرسين 45 و 49.

العدّ بذكاء: المعلومات المتبادلة

العدّ الخام يخدع: كلمات مثل "في" و"من" تجاور كل شيء.

المهم ليس كم مرة ظهرت كلمتان معاً، بل كم مرة أكثر مما نتوقع لو كانتا مستقلتين:

PMI(a,b)=ln⁡P(a,b)P(a) P(b)

إذا ظهرت كلمتان معاً أربعة أضعاف ما نتوقعه بالصدفة: ln⁡4≈1.386، علاقة قوية.

وإذا ظهرتا معاً كما نتوقع بالصدفة: ln⁡1=0، لا علاقة.

نضع صفراً مكان القيم السالبة، لأنها غير موثوقة مع البيانات القليلة.

ثم نضغط الجدول بتحليل القيم المنفردة: قريب جداً من تحليل المكوّنات الرئيسية في الدرس 24. نحتفظ بأهم 64 اتجاهاً.

PPMI · SVD

حدود التضمين الثابت

في كل ما سبق، للكلمة متجه واحد. لكن كلمة "عين" قد تعني عين الإنسان، أو عين الماء، أو الجاسوس!

متجه واحد يخلط كل المعاني.

الترانسفورمرز تحل هذا: تبدأ بالتضمين الثابت، ثم تعدّله طبقة بعد طبقة حسب الكلمات المحيطة. فيصبح لكلمة "عين" في "شربت من العين" متجه مختلف عنه في "أغمض عينه".

import numpy as np
import torch
from torch import nn

words = ["قط", "كلب", "سيارة"]
E = np.array([[0.6, 0.8], [0.8, 0.6], [-0.6, 0.8]])

one_hot = np.array([0, 1, 0])
print("one-hot @ E:", one_hot @ E, "  row 1:", E[1])

def cosine(u, v):
    return u @ v / (np.linalg.norm(u) * np.linalg.norm(v))

for i in range(3):
    for j in range(i + 1, 3):
        print(words[i], words[j], round(cosine(E[i], E[j]), 2))

تضمينات حقيقية من نص شكسبير

نحسبها من الصفر، بالعدّ فقط، في ثوانٍ:

shakespeare_embeddings.pyبايثون
import os
import re
import urllib.request
from collections import Counter
from sklearn.decomposition import TruncatedSVD

URL = "https://raw.githubusercontent.com/karpathy/char-rnn/master/data/tinyshakespeare/input.txt"
if not os.path.exists("tinyshakespeare.txt"):
    urllib.request.urlretrieve(URL, "tinyshakespeare.txt")
tokens = re.findall(r"[a-z']+", open("tinyshakespeare.txt", encoding="utf-8").read().lower())

V = 3000                                              # keep the 3000 most frequent words
vocab = [w for w, _ in Counter(tokens).most_common(V)]
index = {w: i for i, w in enumerate(vocab)}
ids = np.array([index.get(w, -1) for w in tokens])     # -1: rare word, ignored

# 1. co-occurrence counts: neighbours up to 2 words away
C = np.zeros((V, V))
for offset in (1, 2):
    a, b = ids[:-offset], ids[offset:]
    keep = (a >= 0) & (b >= 0)
    np.add.at(C, (a[keep], b[keep]), 1)
    np.add.at(C, (b[keep], a[keep]), 1)

# 2. positive PMI: how much more often together than chance
total = C.sum()
expected = C.sum(axis=1, keepdims=True) * C.sum(axis=0, keepdims=True) / total
with np.errstate(divide="ignore", invalid="ignore"):
    ppmi = np.nan_to_num(np.maximum(np.log(C / expected), 0))

# 3. compress 3000 columns into 64 dimensions, then normalize each vector
vectors = TruncatedSVD(n_components=64, random_state=0).fit_transform(ppmi)
vectors /= np.linalg.norm(vectors, axis=1, keepdims=True)
print("embedding matrix:", vectors.shape)

neighbours.pyبايثون
def neighbours(word, k=6):
    sims = vectors @ vectors[index[word]]
    return [vocab[i] for i in np.argsort(-sims)[1:k + 1]]     # skip the word itself

for w in ["king", "father", "three", "eyes", "night", "sword"]:
    print(f"{w:7} -> {neighbours(w)}")

ماذا عن الحساب بالكلمات؟

المثال المشهور: الملك، ناقص الرجل، زائد المرأة، يعطي الملكة. نجرّبه:

analogy.pyبايثون
def analogy(a, b, c, k=4):
    """a is to b as c is to ?"""
    v = vectors[index[b]] - vectors[index[a]] + vectors[index[c]]
    sims = vectors @ (v / np.linalg.norm(v))
    return [vocab[i] for i in np.argsort(-sims) if vocab[i] not in (a, b, c)][:k]

print("man : king  ::  woman : ?", analogy("man", "king", "woman"))
print("he  : his   ::  she   : ?", analogy("he", "his", "she"))

سؤال مقابلة

سؤال قد تسمعه في المقابلة:

What is an embedding layer and how does it relate to one-hot encoding?

جواب قصير وجيد:

An embedding layer is a learnable matrix with one row per token. Looking up a token's row is mathematically the same as multiplying its one-hot vector by the matrix, but done as an index lookup for efficiency. The rows are trained by backpropagation together with the rest of the model, so tokens used in similar contexts end up with similar vectors.

سؤال قد تسمعه في المقابلة:

Why is cosine similarity preferred over Euclidean distance for embeddings?

جواب قصير وجيد:

Cosine similarity compares directions and ignores vector length. Embedding lengths often reflect things like word frequency rather than meaning, so the angle is a more reliable measure of semantic similarity.

سؤال قد تسمعه في المقابلة:

What is the difference between static and contextual embeddings?

جواب قصير وجيد:

A static embedding gives each word one vector regardless of context, so ambiguous words mix their meanings. Contextual embeddings, produced by models like transformers, give a different vector for each occurrence depending on the surrounding words.

الخلاصة
  • رقم الرمز عنوان فقط. والمتجه الأحادي ضخم، وكل الكلمات فيه متساوية البعد.
  • التضمين: جدول متجهات كثيفة، صف لكل رمز. والبحث فيه يساوي ضرب المتجه الأحادي في الجدول.
  • المتجهات تُتعلَّم. والكلمات المتشابهة في الاستخدام تصبح متقاربة.
  • تعرف الكلمة من رفاقها: العدّ مع المعلومات المتبادلة، ثم الضغط، يعطي تضمينات مفيدة.
  • التشابه بجيب التمام: الاتجاه، لا الطول.
  • التضمين الثابت متجه واحد لكل كلمة. الترانسفورمرز تجعله سياقياً.
