الأوزان الكبيرة: علامة خطر

تذكّر كثيرة الحدود من الدرجة العالية في الدرس 27. لكي تتلوّى وتمر بكل نقطة، تحتاج أوزاناً ضخمة:

وزن موجب هائل، ثم سالب هائل، يلغي بعضها بعضاً عند نقاط التدريب بالضبط.

وبين النقاط، هذه الأوزان الهائلة تصنع قفزات مجنونة.

الفكرة إذن: عاقب الأوزان الكبيرة. أضف إلى الخسارة حداً يكبر مع حجم الأوزان:

Ltotal=MSE+λ∑jwj2

الآن النموذج يوازن بين هدفين: أن يطابق البيانات، وأن تبقى أوزانه صغيرة.

خطوة نزول مع العقوبة

وزن قيمته 3، ومشتقة متوسط المربعات بالنسبة له 0.5، ومعدل التعلّم 0.1.

بدون عقوبة:

w=3−0.1×0.5=2.95

مع عقوبة المربعات بقوة 0.1: مشتقة العقوبة 2λw=0.6:

w=3−0.1×(0.5+0.6)=2.89

نفس الشيء بشكل آخر:

w=3×(1−2×0.1×0.1)−0.1×0.5=3×0.98−0.05=2.89

كل خطوة تضرب الوزن في 0.98 أولاً، ثم تكمل الخطوة العادية. لذلك اسمها اضمحلال الأوزان.

weight decay
لماذا تصفّر عقوبة القيم المطلقة، ولا تصفّر المربعات؟

وزن صغير قيمته 0.02، والبيانات لا تدفعه في أي اتجاه: مشتقة الخطأ صفر.

مع المربعات: تُضرب القيمة في 0.98 كل خطوة: 0.0196، ثم 0.0192... تصغر ولا تصل إلى الصفر أبداً.

مع القيم المطلقة: مشتقة العقوبة ثابتة، λ فقط مهما صغر الوزن. خطوة بحجم 0.1×0.1=0.01:

0.02، ثم 0.01، ثم صفر.

الدفعة الثابتة توصل الوزن إلى الصفر. والدفعة المتناسبة تضعف كلما اقتربت.

ridge_poly.pyبايثون
import numpy as np
import matplotlib.pyplot as plt
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import PolynomialFeatures, StandardScaler
from sklearn.linear_model import LinearRegression, Ridge

rng = np.random.default_rng(1)
f = lambda x: np.sin(2.6 * x) * 1.2 + 0.4 * x
x = np.sort(rng.uniform(-1, 1, 15)); y = f(x) + rng.normal(0, 0.28, 15)
xv = rng.uniform(-1, 1, 200); yv = f(xv) + rng.normal(0, 0.28, 200)

xx = np.linspace(-1, 1, 400)
plt.figure(figsize=(6.4, 3.8))
plt.scatter(x, y, color="C1", zorder=3, label="train points")
for alpha in [None, 1e-4, 1e-2, 10]:
    reg = LinearRegression() if alpha is None else Ridge(alpha=alpha)
    m = make_pipeline(PolynomialFeatures(15, include_bias=False), StandardScaler(), reg).fit(x[:, None], y)
    val_mse = np.mean((m.predict(xv[:, None]) - yv) ** 2)
    biggest = np.abs(m[-1].coef_).max()
    print(f"alpha = {str(alpha):6}  largest weight = {biggest:12.1f}   validation MSE = {val_mse:12.3f}")
    plt.plot(xx, m.predict(xx[:, None]), lw=2, label=f"alpha = {alpha}")
plt.ylim(-3, 3); plt.legend(fontsize=8); plt.grid(True)
plt.show()

lasso.pyبايثون
from sklearn.datasets import load_diabetes
from sklearn.model_selection import train_test_split
from sklearn.linear_model import Lasso
from sklearn.metrics import r2_score

data = load_diabetes()
X_tr, X_te, y_tr, y_te = train_test_split(data.data, data.target, test_size=0.25, random_state=0)
scaler = StandardScaler().fit(X_tr)
Xs_tr, Xs_te = scaler.transform(X_tr), scaler.transform(X_te)

for alpha in [0.01, 1, 3, 10]:
    lasso = Lasso(alpha=alpha).fit(Xs_tr, y_tr)
    kept = [n for n, c in zip(data.feature_names, lasso.coef_) if c != 0]
    print(f"alpha = {alpha:<5} features kept = {len(kept):2d}   test R2 = {r2_score(y_te, lasso.predict(Xs_te)):.3f}   {kept}")

سؤال مقابلة

سؤال قد تسمعه في المقابلة:

What is the difference between L1 and L2 regularization?

جواب قصير وجيد:

Both add a penalty on the weights to the loss to reduce overfitting. L2 adds the sum of squared weights: it shrinks all weights smoothly but rarely makes them exactly zero; in gradient descent it acts as weight decay. L1 adds the sum of absolute values: its constant push drives many weights to exactly zero, so it also does feature selection. Features should be standardized, and the strength is chosen by cross-validation.

الخلاصة
  • الأوزان الكبيرة علامة تلوّي وإفراط. التنظيم يعاقبها.
  • عقوبة المربعات تصغّر كل الأوزان. وفي النزول بالتدرّج هي اضمحلال الأوزان.
  • عقوبة القيم المطلقة تجعل أوزاناً كثيرة صفراً: تختار الميزات.
  • وحّد الميزات قبل التنظيم، ولا تعاقب الإزاحة.
  • القوة المناسبة بالتحقق المتقاطع: ضعيفة جداً تفرط، وقوية جداً تقلل التعلّم.

تلميح

مشتقة عقوبة المربعات 2λw. ومشتقة القيم المطلقة λ ضرب إشارة الوزن.

الحل (افتحه بعد أن تحاول)

المربعات: الخطوة w−0.1×2×0.5×w=0.9w. بعد 3 خطوات:

2×0.93=1.458

القيم المطلقة: الخطوة تنقص 0.1×0.5=0.05 ثابتة. من 2 إلى الصفر: 2/0.05=40 خطوة.

بايثون
w_l2, w_l1 = 2.0, 2.0
for _ in range(50):
    w_l2 -= 0.1 * 2 * 0.5 * w_l2
    step = 0.1 * 0.5 * np.sign(w_l1)
    w_l1 = 0.0 if abs(w_l1) <= abs(step) else w_l1 - step
print("L2 after 50 steps:", round(w_l2, 5))
print("L1 after 50 steps:", w_l1)

وزن قيمته 2. البيانات لا تدفعه أبداً: مشتقة الخطأ صفر دائماً. معدل التعلّم 0.1، وقوة التنظيم 0.5.

1. مع عقوبة المربعات: بكم يُضرب الوزن في كل خطوة؟ وما قيمته بعد 3 خطوات؟
2. مع عقوبة القيم المطلقة: كم ينقص في كل خطوة؟ وبعد كم خطوة يصل إلى الصفر؟
3. اكتب حلقة بايثون تحاكي الحالتين 50 خطوة، واطبع القيمة النهائية. للثانية: إذا عبر الوزن الصفر، اجعله صفراً.
المربعات: الخطوة $w - 0.1 \times 2 \times 0.5 \times w = 0.9w$. بعد 3 خطوات:

$$2 \times 0.9^3 = 1.458$$

القيم المطلقة: الخطوة تنقص $0.1 \times 0.5 = 0.05$ ثابتة. من 2 إلى الصفر: $2 / 0.05 = 40$ خطوة.

```python
w_l2, w_l1 = 2.0, 2.0
for _ in range(50):
    w_l2 -= 0.1 * 2 * 0.5 * w_l2
    step = 0.1 * 0.5 * np.sign(w_l1)
    w_l1 = 0.0 if abs(w_l1) <= abs(step) else w_l1 - step
print("L2 after 50 steps:", round(w_l2, 5))
print("L1 after 50 steps:", w_l1)
```
