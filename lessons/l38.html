التدرّج التلقائي

نعلّم الموتر بخيار واحد، فتسجّل باي تورش كل عملية عليه:

requires_grad=True

بعد حساب الخسارة، استدعاء واحد يحسب كل التدرّجات بالانتشار العكسي:

والتدرّج يُحفظ في خاصية داخل كل موتر:

نزول بالتدرّج، بالتدرّج التلقائي

manual_gd.pyبايثون
w = torch.tensor(1.0, requires_grad=True)
b = torch.tensor(1.0, requires_grad=True)
for step in range(3):
    loss = (w * x + b - y) ** 2
    loss.backward()
    with torch.no_grad():            # the update itself must not be recorded
        w -= 0.01 * w.grad
        b -= 0.01 * b.grad
    w.grad.zero_(); b.grad.zero_()
    print(f"step {step}: loss before update = {loss.item():.4f}")

from torch import nn

class MLP(nn.Module):
    def __init__(self, d_in, d_hidden, n_classes):
        super().__init__()
        self.hidden = nn.Linear(d_in, d_hidden)
        self.act = nn.ReLU()
        self.out = nn.Linear(d_hidden, n_classes)

    def forward(self, x):
        return self.out(self.act(self.hidden(x)))     # logits

torch.manual_seed(0)

spiral_torch.pyبايثون
from torch.utils.data import DataLoader, TensorDataset

def make_spiral(n_per_class=100, n_classes=3, noise=0.2, seed=0):
    rng = np.random.default_rng(seed)
    X, y = [], []
    for k in range(n_classes):
        r = np.linspace(0.0, 1.0, n_per_class)
        t = np.linspace(4 * k, 4 * (k + 1), n_per_class) + rng.normal(0, noise, n_per_class)
        X.append(np.column_stack([r * np.sin(t), r * np.cos(t)]))
        y.append(np.full(n_per_class, k))
    return np.vstack(X), np.concatenate(y)

X, y = make_spiral()
idx = np.random.default_rng(1).permutation(len(X))
X_tr = torch.tensor(X[idx[:240]], dtype=torch.float32)
y_tr = torch.tensor(y[idx[:240]], dtype=torch.long)       # class indices: integers
X_val = torch.tensor(X[idx[240:]], dtype=torch.float32)
y_val = torch.tensor(y[idx[240:]], dtype=torch.long)

torch.manual_seed(0)
model = MLP(2, 64, 3)
loss_fn = nn.CrossEntropyLoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.5)
loader = DataLoader(TensorDataset(X_tr, y_tr), batch_size=32, shuffle=True)

def accuracy(model, X, y):
    model.eval()
    with torch.no_grad():
        return (model(X).argmax(dim=1) == y).float().mean().item()

for epoch in range(1, 201):
    model.train()
    for xb, yb in loader:
        loss = loss_fn(model(xb), yb)
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
    if epoch % 50 == 0:
        with torch.no_grad():
            val_loss = loss_fn(model(X_val), y_val).item()
        print(f"epoch {epoch}: val loss {val_loss:.3f}, val acc {accuracy(model, X_val, y_val):.3f}")

سؤال مقابلة

سؤال قد تسمعه في المقابلة:

What does optimizer.zero_grad() do, and why is it needed?

جواب قصير وجيد:

PyTorch accumulates gradients in the .grad attribute every time backward() is called. zero_grad() resets them, so each step uses only the gradient of the current mini-batch. Accumulation is intentional: it allows gradient accumulation across several small batches to simulate a larger batch.

سؤال قد تسمعه في المقابلة:

Why does nn.CrossEntropyLoss take raw logits instead of probabilities?

جواب قصير وجيد:

It combines log-softmax and negative log-likelihood in one numerically stable operation. Applying softmax before it would apply softmax twice, giving a wrong loss and weaker gradients.

سؤال قد تسمعه في المقابلة:

What is the difference between model.eval() and torch.no_grad()?

جواب قصير وجيد:

model.eval() switches layers like dropout and batch normalization to inference behavior. torch.no_grad() stops autograd from recording operations, which saves memory and time. For evaluation you usually use both.

الخلاصة
  • باي تورش تعطيك: موترات على كرت الشاشة، وتدرّجاً تلقائياً، وطبقات، وخسائر، ومحسّنات، ومحمّلات بيانات.
  • التدرّج التلقائي: علّم الموتر، ثم نادِ الانتشار العكسي، ثم اقرأ التدرّج. والتدرّجات تتراكم، فصفّرها قبل كل خطوة.
  • الشبكة صنف يرث من الوحدة الأساسية: طبقات في البناء، وتمرير أمامي فقط.
  • الطبقة الجاهزة تحفظ الأوزان بشكل (المخرجات، المدخلات).
  • الخسارة الجاهزة للتصنيف تأخذ الدرجات الخام. لا سوفتماكس قبلها.
  • خطوة التدريب: للأمام، الخسارة، تصفير، للخلف، خطوة.
  • للتقييم: وضع التقييم، مع إيقاف تسجيل التدرّج.
