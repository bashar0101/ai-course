العربية والرموز

المقطّع يتعلّم الدمجات من النصوص التي درّبناه عليها.

إذا كانت أغلب النصوص إنجليزية، فأغلب الدمجات إنجليزية. والعربية تبقى مقسمة إلى قطع صغيرة، وأحياناً إلى بايتات منفردة.

النتيجة: نفس المعنى بالعربية يأخذ رموزاً أكثر. وهذا يعني:

  • تكلفة أعلى: الواجهات البرمجية تحسب السعر بالرموز، كما سنرى في الدرس 54.
  • ذاكرة أقصر: نافذة السياق محدودة بعدد الرموز، فيتسع لنص عربي أقل.
  • بطء أكبر: النموذج يولّد رمزاً في كل خطوة.

المقطّعات الحديثة متعددة اللغات أفضل بكثير مع العربية. لكن لا تفترض: قِس دائماً بمقطّع النموذج الذي تستخدمه.

الرموز الخاصة

بعض الرموز لا تأتي من النص. نضيفها للمفردات يدوياً، ولا تُقسم أبداً:

  • رمز نهاية النص: يفصل بين المستندات أثناء التدريب، ويخبر النموذج متى يتوقف.
  • رمز الحشو: يملأ الفراغ لكي تتساوى أطوال الجمل في الدفعة.
  • رموز المحادثة: تحدد بداية رسالة المستخدم ورسالة المساعد. نراها في الدرس 51.
<|endoftext|> · [PAD] · chat markers

bpe.pyبايثون
from collections import Counter

def train_bpe(word_counts, n_merges):
    """word_counts: {word: count}. Returns the merge rules and the final segmentation."""
    words = {w: list(w) for w in word_counts}              # start from characters
    merges = []
    for _ in range(n_merges):
        pairs = Counter()
        for w, toks in words.items():
            for a, b in zip(toks, toks[1:]):
                pairs[(a, b)] += word_counts[w]           # weighted by word frequency
        if not pairs:
            break
        best = max(pairs, key=pairs.get)                   # ties: the first pair seen wins
        merges.append(best)
        for w in words:
            words[w] = apply_merge(words[w], best)
    return merges, words

def apply_merge(toks, pair):
    out, i = [], 0
    while i < len(toks):
        if i + 1 < len(toks) and (toks[i], toks[i + 1]) == pair:
            out.append(toks[i] + toks[i + 1])
            i += 2
        else:
            out.append(toks[i])
            i += 1
    return out

def encode_word(word, merges):
    toks = list(word)
    for pair in merges:                                    # same order as training
        toks = apply_merge(toks, pair)
    return toks

corpus = {"كتب": 8, "كتاب": 4, "مكتب": 6, "مكتبة": 2, "يكتب": 5}
merges, words = train_bpe(corpus, 3)
print("merges:", merges)
print("words :", words)
for w in ["يكتبون", "مكتوب", "كاتب", "فكتب"]:
    print(w, "->", encode_word(w, merges))

اقرأ النتائج:

  • جملة شكسبير: كلمات كاملة تقريباً، لأن المقطّع تدرب على هذا النص.
  • الجملة الإنجليزية الحديثة: كلمات حديثة، مثل الذكاء الاصطناعي، لم تظهر كثيراً عند شكسبير، فقُسمت إلى قطع.

مقطّع لا يطابق النموذج

كل نموذج تدرّب مع مقطّع واحد محدد. رقم الرمز 403 في مقطّع يعني شيئاً مختلفاً تماماً في مقطّع آخر.

استخدام مقطّع نموذج آخر يعطي نموذجك أرقاماً بلا معنى. حمّل المقطّع دائماً من نفس مصدر النموذج.

سؤال مقابلة

سؤال قد تسمعه في المقابلة:

Why do modern language models use subword tokenization?

جواب قصير وجيد:

Word-level vocabularies are huge and cannot handle unseen words, while character-level tokenization produces very long sequences and forces the model to learn spelling. Subword methods such as BPE keep frequent words as single tokens and split rare words into known pieces, which gives a manageable vocabulary, reasonable sequence lengths and no out-of-vocabulary words when combined with byte-level fallback.

سؤال قد تسمعه في المقابلة:

How does byte-pair encoding work?

جواب قصير وجيد:

Start with a vocabulary of bytes or characters. Repeatedly count all adjacent symbol pairs in the training corpus, merge the most frequent pair into a new symbol, and record the merge. Stop at the target vocabulary size. To tokenize new text, apply the learned merges in the same order.

سؤال قد تسمعه في المقابلة:

Why do LLMs sometimes fail to count the letters in a word?

جواب قصير وجيد:

The model does not see letters. It sees tokens, which are often whole words or word pieces. The number of letters inside a token is not directly visible in the input and must be memorized indirectly.

الخلاصة
  • النموذج يرى أرقاماً. المقطّع يقسم النص إلى رموز، ويعطي كل رمز رقماً.
  • الحروف: تسلسلات طويلة. الكلمات: مفردات ضخمة وكلمات مجهولة. أجزاء الكلمات: الحل الوسط.
  • خوارزمية أزواج البايتات: ادمج أكثر زوج متجاور تكراراً، وكرر. والتقطيع: طبّق الدمجات بالترتيب.
  • البدء من البايتات يعني لا رمز مجهول أبداً.
  • مقطّع تدرّب على نص إنجليزي يقسم العربية إلى قطع كثيرة: تكلفة أعلى، وسياق أقصر.
  • كل نموذج له مقطّعه. لا تخلط بينها.
