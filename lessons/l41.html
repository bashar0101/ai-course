القنوات

الصورة الملونة ثلاث طبقات فوق بعضها: أحمر وأخضر وأزرق. لذلك المرشّح أيضاً له عمق 3: شكله 3×3×3، ويجمع عبر القنوات الثلاث.

والطبقة الالتفافية فيها عدة مرشّحات، كل واحد يبحث عن صفة مختلفة. كل مرشّح يعطي خريطة صفات، والخرائط كلها فوق بعضها تصبح قنوات المخرج.

عدد معاملات طبقة التفافية:

(K×K×Cin+1)×Cout

مثال: صورة ملونة، و 16 مرشّحاً بحجم 3 في 3:

(3×3×3+1)×16=448

448 معاملاً فقط، مهما كان حجم الصورة!

الشبكة الالتفافية كاملة

الشكل المعتاد: عدة مرات من التفاف ثم ريلو ثم تجميع. ثم نفرد المصفوفة إلى متجه، ونضع طبقة كاملة الاتصال أو اثنتين للتصنيف.

ماذا تتعلّم الطبقات؟

  • الطبقة الأولى: صفات بسيطة، مثل الحواف والألوان.
  • الطبقات الوسطى: تركّب الحواف في زوايا وأنسجة وأشكال صغيرة.
  • الطبقات العميقة: أجزاء كاملة، مثل عين أو عجلة.

كل تجميع يوسّع مجال الرؤية: عصبون في طبقة عميقة يتأثر بمساحة كبيرة من الصورة الأصلية، رغم أن كل مرشّح صغير.

الوصلات المتبقية، ونقل التعلّم

الوصلات المتبقية. الشبكات العميقة جداً كانت صعبة التدريب: التدرّج يضعف عبر طبقات كثيرة.

الحل الذي غيّر المجال عام 2015: كل كتلة تحسب تعديلاً على مدخلها، بدل مخرج جديد تماماً:

y=x+F(x)

التدرّج يمر عبر الجمع مباشرة، كطريق سريع. هكذا دُرّبت شبكات من أكثر من مئة طبقة. وستجد نفس الوصلة في كل كتلة ترانسفورمر، في الدرس 48.

residual connection (ResNet)

نقل التعلّم. لا تدرّب شبكة صور من الصفر إلا نادراً. خذ شبكة مدرّبة على ملايين الصور، واستبدل آخر طبقة بطبقة لفئاتك، ودرّب على بياناتك القليلة.

الطبقات الأولى تعرف الحواف والأشكال مسبقاً. نفس الفكرة مع النماذج اللغوية في الدرس 53.

conv_by_hand.pyبايثون
import numpy as np
import torch
import torch.nn.functional as F
from torch import nn

def conv2d(image, kernel):
    """Slide the kernel over the image: multiply element-wise and sum (no padding, stride 1)."""
    k = kernel.shape[0]
    n = image.shape[0] - k + 1
    out = np.zeros((n, n))
    for i in range(n):
        for j in range(n):
            out[i, j] = np.sum(image[i:i + k, j:j + k] * kernel)
    return out

image = np.array([[0, 0, 9, 9, 9]] * 5, dtype=float)
vertical_edge = np.array([[-1, 0, 1]] * 3, dtype=float)
print(conv2d(image, vertical_edge))

# same computation in PyTorch; shapes: (batch, channels, height, width)
t = F.conv2d(torch.tensor(image)[None, None], torch.tensor(vertical_edge)[None, None])
print(t[0, 0])

def make_cnn():
    torch.manual_seed(0)
    return nn.Sequential(
        nn.Conv2d(1, 16, kernel_size=3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
        nn.Conv2d(16, 32, kernel_size=3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
        nn.Flatten(),
        nn.Linear(32 * 2 * 2, 10))

def make_mlp():
    torch.manual_seed(0)
    return nn.Sequential(nn.Flatten(), nn.Linear(64, 128), nn.ReLU(), nn.Linear(128, 10))

def count(model):
    return sum(p.numel() for p in model.parameters())

train_compare.pyبايثون
def shift(X, dx=0, dy=0):
    """Move images dx pixels right and dy pixels down, filling the gap with zeros."""
    out = torch.roll(X, shifts=(dy, dx), dims=(2, 3))
    if dx > 0: out[..., :, :dx] = 0
    if dx < 0: out[..., :, dx:] = 0
    if dy > 0: out[..., :dy, :] = 0
    if dy < 0: out[..., dy:, :] = 0
    return out

def train(model, epochs=30, augment=False):
    opt = torch.optim.Adam(model.parameters(), lr=3e-3)
    loss_fn = nn.CrossEntropyLoss()
    g = torch.Generator().manual_seed(0)
    for _ in range(epochs):
        model.train()
        for idx in torch.randperm(len(X_tr), generator=g).split(32):
            xb = X_tr[idx]
            if augment:                                   # random shift of -1, 0 or +1 pixel
                dx, dy = torch.randint(-1, 2, (2,), generator=g).tolist()
                xb = shift(xb, dx, dy)
            loss = loss_fn(model(xb), y_tr[idx])
            opt.zero_grad(); loss.backward(); opt.step()
    return model

def accuracy(model, X):
    model.eval()
    with torch.no_grad():
        return (model(X).argmax(1) == y_te).float().mean().item()

for name, make in [("MLP", make_mlp), ("CNN", make_cnn)]:
    model = train(make())
    print(f"{name}: test {accuracy(model, X_te):.3f} | shifted 1px {accuracy(model, shift(X_te, 1)):.3f}"
          f" | shifted 2px {accuracy(model, shift(X_te, 2)):.3f}")

سؤال مقابلة

سؤال قد تسمعه في المقابلة:

Why are convolutional networks better than fully connected networks for images?

جواب قصير وجيد:

Convolutions use local connectivity and weight sharing. Each filter looks at a small patch and the same filter is applied everywhere, so the number of parameters does not depend on the image size and a feature learned in one location is detected in every location. This builds in the prior that nearby pixels are related and that objects can appear anywhere. Pooling adds some tolerance to small shifts.

سؤال قد تسمعه في المقابلة:

How do you compute the output size of a convolution?

جواب قصير وجيد:

For input width W, kernel size K, padding P and stride S, the output width is (W - K + 2P) / S + 1. For example, a 3×3 kernel with padding 1 and stride 1 keeps the size unchanged.

سؤال قد تسمعه في المقابلة:

How many parameters does a conv layer with 3 input channels, 16 filters of size 3×3 have?

جواب قصير وجيد:

Each filter has 3 × 3 × 3 weights plus one bias, so 28 per filter, times 16 filters, which is 448 parameters, independent of the image size.

الخلاصة
  • الشبكة العادية تحتاج أوزاناً هائلة للصور، ولا تعرف أن البكسلات المتجاورة مرتبطة.
  • الالتفاف: مرشّح صغير ينزلق على الصورة، ضرب ثم جمع. نفس الأوزان في كل مكان.
  • حجم المخرج: (W−K+2P)/S+1.
  • المعاملات: (K×K×Cin+1)×Cout، ولا تعتمد على حجم الصورة.
  • التجميع بالأكبر يصغّر الخريطة للنصف، بدون معاملات.
  • الشكل المعتاد: التفاف، ريلو، تجميع، مكررة، ثم فرد وتصنيف.
  • الوصلات المتبقية تسمح بشبكات عميقة جداً، ونقل التعلّم يوفّر التدريب من الصفر.
  • زيادة البيانات تعلّم الشبكة ما لا يغيّر الجواب.

  5. فرد، ثم طبقة كاملة الاتصال إلى 10.

تلميح

استخدم القانون للالتفاف. التجميع يقسم العرض والارتفاع على 2. والفرد يضرب القنوات في العرض في الارتفاع.

الحل (افتحه بعد أن تحاول)
  • الالتفاف الأول: (32−5+0)/1+1=28. الشكل 8×28×28. المعاملات (5×5×3+1)×8=608.
  • التجميع: 8×14×14.
  • الالتفاف الثاني: (14−3+2)/1+1=14. الشكل 16×14×14. المعاملات (3×3×8+1)×16=1,168.
  • التجميع: 16×7×7.
  • الفرد: 16×7×7=784. والطبقة الأخيرة: 784×10+10=7,850.
  • المجموع: 608+1,168+7,850=9,626.
