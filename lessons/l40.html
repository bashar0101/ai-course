الشبكة تستطيع حفظ أي شيء

في الدرس 27 رأينا الإفراط في التعلّم: نموذج يحفظ التدريب، ويفشل في البيانات الجديدة.

الشبكات العصبية فيها معاملات كثيرة جداً، فهي قادرة على الحفظ أكثر من أي نموذج رأيناه.

تجربة مشهورة: خذ صور أرقام، واستبدل كل الأجوبة بأرقام عشوائية لا معنى لها. ثم درّب شبكة.

النتيجة: الشبكة تصل إلى دقة 100% على التدريب! حفظت كل صورة مع جوابها العشوائي.

وعلى البيانات الجديدة؟ حوالي 10%، أي تخمين عشوائي. سنجربها بالكود.

دقة تدريب عالية لا تعني شيئاً وحدها. الشبكة تستطيع أن تحفظ حتى الضجيج. المقياس الحقيقي دائماً بيانات التحقق.

تقليص الأوزان، وآدم دبليو

في الدرس 32 أضفنا عقوبة على مربعات الأوزان. تدرّج هذه العقوبة λw.

مع النزول العادي، خطوة التدريب تصبح:

w←w−η(g+λw)=(1−ηλ) w−η g

أي: قبل كل خطوة، نضرب الوزن في رقم أصغر قليلاً من واحد. لذلك اسمها تقليص الأوزان.

weight decay

لكن مع آدم تظهر مشكلة: آدم يقسم التدرّج كله على حجمه المعتاد، بما فيه جزء العقوبة.

فالأوزان ذات التدرّجات الكبيرة تتقلص أقل من غيرها. التنظيم يصبح غير متساوٍ.

الحل: آدم دبليو يفصل التقليص عن التدرّج. يأخذ خطوة آدم العادية، ثم يقلّص الوزن مباشرة:

w←w−η m^s^+ϵ−ηλw
AdamW

هذا المحسِّن المستخدم في تدريب كل النماذج اللغوية الحديثة تقريباً.

الإسقاط

في كل خطوة تدريب، نطفئ كل عصبون مخفي باحتمال p، مثلاً نصف العصبونات. عصبون مطفأ مخرجه صفر في هذه الخطوة.

في الخطوة التالية نطفئ مجموعة عشوائية أخرى.

dropout

لماذا يفيد؟

  • لا يستطيع أي عصبون أن يعتمد على عصبون آخر بعينه، لأنه قد يختفي. فتتعلّم الشبكة صفات أقوى وأكثر توزيعاً.
  • كل خطوة تدرّب شبكة فرعية مختلفة. والشبكة النهائية تشبه متوسط آلاف الشبكات الفرعية، مثل الغابة العشوائية في الدرس 21.

التكبير: لكي لا يتغير المجموع

إذا أطفأنا ربع العصبونات، ينقص مجموع ما يصل للطبقة التالية تقريباً بالربع.

وفي التقييم نشغّل كل العصبونات، فيعود المجموع كاملاً. الطبقة التالية سترى مقاييس مختلفة بين التدريب والتقييم!

الحل: أثناء التدريب، نقسم كل عصبون باقٍ على 1−p. فيبقى المتوقع كما هو:

E[out]=(1−p)×h1−p+p×0=h

وفي التقييم: لا إطفاء، ولا تكبير.

الإيقاف المبكر

راقب خسارة التحقق بعد كل حقبة. في البداية تنزل مع خسارة التدريب. ثم تتوقف، وتبدأ بالصعود: بدأ الحفظ.

الإيقاف المبكر: احفظ الأوزان عند أفضل خسارة تحقق. وإذا مرت عدة حقب بدون تحسن، أوقف التدريب واسترجع الأوزان المحفوظة.

early stopping · patience

عدد الحقب التي ننتظرها اسمه الصبر. لا نوقف عند أول ارتفاع، لأن خسارة التحقق فيها ضجيج، وقد تنزل مرة أخرى.

import copy
import numpy as np
import torch
from torch import nn
from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split

X, y = load_digits(return_X_y=True)          # 1797 images, 8x8 pixels, digits 0-9
X = X / 16.0                                  # pixels 0..16 -> 0..1
X_tr, X_rest, y_tr, y_rest = train_test_split(X, y, train_size=300, stratify=y, random_state=0)
X_val, X_te, y_val, y_te = train_test_split(X_rest, y_rest, test_size=0.5,
                                            stratify=y_rest, random_state=0)

def to_t(a, dtype=torch.float32):
    return torch.tensor(a, dtype=dtype)

X_tr, X_val, X_te = to_t(X_tr), to_t(X_val), to_t(X_te)
y_tr, y_val, y_te = to_t(y_tr, torch.long), to_t(y_val, torch.long), to_t(y_te, torch.long)

# replace 20% of the training labels with random digits
g = torch.Generator().manual_seed(2)
y_noisy = y_tr.clone()
flip = torch.rand(len(y_noisy), generator=g) < 0.2
y_noisy[flip] = torch.randint(0, 10, (int(flip.sum()),), generator=g)
print("train / val / test:", len(X_tr), len(X_val), len(X_te))
print("wrong training labels:", int((y_noisy != y_tr).sum()))

دالة التدريب، مع الإيقاف المبكر

train_fn.pyبايثون
loss_fn = nn.CrossEntropyLoss()

def make_model(p_drop=0.0):
    torch.manual_seed(0)
    return nn.Sequential(
        nn.Linear(64, 256), nn.ReLU(), nn.Dropout(p_drop),
        nn.Linear(256, 256), nn.ReLU(), nn.Dropout(p_drop),
        nn.Linear(256, 10))

def evaluate(model, X, y):
    model.eval()                                          # dropout OFF
    with torch.no_grad():
        logits = model(X)
        return loss_fn(logits, y).item(), (logits.argmax(1) == y).float().mean().item()

def train(model, opt, labels, epochs=200, patience=None, batch_size=32):
    g = torch.Generator().manual_seed(0)
    history, best = [], {"loss": float("inf")}
    for epoch in range(1, epochs + 1):
        model.train()                                     # dropout ON
        for idx in torch.randperm(len(X_tr), generator=g).split(batch_size):
            loss = loss_fn(model(X_tr[idx]), labels[idx])
            opt.zero_grad(); loss.backward(); opt.step()
        val_loss, val_acc = evaluate(model, X_val, y_val)
        history.append((evaluate(model, X_tr, labels)[1], val_loss, val_acc))
        if val_loss < best["loss"]:                        # remember the best weights
            best = {"loss": val_loss, "epoch": epoch, "acc": val_acc,
                    "state": copy.deepcopy(model.state_dict())}
        elif patience and epoch - best["epoch"] >= patience:
            break                                         # early stopping
    return np.array(history), best

نسيان وضع التقييم

إذا قيّمت الشبكة وهي في وضع التدريب، يبقى الإسقاط يعمل: التوقعات عشوائية، والدقة أقل من الحقيقية، وتتغير كل مرة.

قاعدة: وضع التقييم قبل أي تقييم أو استخدام، ووضع التدريب قبل التدريب.

سؤال مقابلة

سؤال قد تسمعه في المقابلة:

How does dropout work, and why does it help?

جواب قصير وجيد:

During training, dropout sets each activation to zero with probability p and scales the survivors by 1/(1 - p), so the expected value is unchanged. At inference it does nothing. It prevents neurons from co-adapting, forcing redundant and robust features, and it acts like training an ensemble of many thinned sub-networks that share weights.

سؤال قد تسمعه في المقابلة:

What is the difference between Adam with L2 regularization and AdamW?

جواب قصير وجيد:

With L2 in the loss, the penalty gradient is added to the gradient and then rescaled by Adam's per-parameter normalization, so weights with large gradients are regularized less. AdamW decouples weight decay: it applies the decay directly to the weights, separately from the adaptive gradient step. This gives more consistent regularization and usually better generalization.

سؤال قد تسمعه في المقابلة:

How does early stopping work?

جواب قصير وجيد:

Monitor the validation loss each epoch, save the weights whenever it improves, and stop when it has not improved for a number of epochs called the patience. Then restore the best saved weights.

الخلاصة
  • الشبكات تستطيع حفظ أي شيء، حتى الأجوبة العشوائية. دقة التدريب وحدها لا تعني شيئاً.
  • تقليص الأوزان: ضرب كل وزن في رقم أصغر قليلاً من واحد في كل خطوة. ومع آدم، استخدم آدم دبليو.
  • الإسقاط: إطفاء عصبونات عشوائية في التدريب فقط، وتكبير الباقي بالقسمة على 1−p.
  • الإيقاف المبكر: احفظ أفضل أوزان حسب التحقق، وتوقف بعد عدد حقب الصبر بدون تحسن.
  • وضع التقييم قبل أي تقييم، لكي يتوقف الإسقاط.
