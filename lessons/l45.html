المهمة: توقّع الرمز التالي

النموذج اللغوي يجيب عن سؤال واحد فقط: ما الرمز التالي؟

ليس جواباً واحداً، بل احتمال لكل رمز في المفردات.

"ذهبت إلى السوق لأشتري ..." خبزاً باحتمال عالٍ، وسيارة باحتمال أقل، وغيمة باحتمال قريب من الصفر.

language model · next-token prediction

ومن هذا السؤال البسيط يأتي كل شيء: نختار رمزاً من الاحتمالات، ونضيفه للنص، ونسأل مرة أخرى. هكذا تكتب النماذج اللغوية الكبيرة. هذه المهمة وحدها، بنموذج ضخم وبيانات هائلة، هي أساس كل ما سنراه في الجزء القادم.

احتمال جملة كاملة

من قاعدة السلسلة في الاحتمالات، الدرس 11: احتمال تسلسل يساوي حاصل ضرب احتمالات كل رمز بشرط ما قبله:

P(x1,x2,…,xn)=P(x1) P(x2∣x1) P(x3∣x1,x2)⋯P(xn∣x1,…,xn−1)

هذه ليست تقريباً: هي صحيحة دائماً. والنموذج اللغوي يحاول أن يتعلّم كل عامل فيها.

chain rule of probability

أبسط نموذج: الثنائيات

المشكلة: الشرط "كل ما قبله" يطول مع النص. أبسط تبسيط: انظر إلى الرمز السابق فقط:

P(xt∣x1,…,xt−1)≈P(xt∣xt−1)

وكيف نقدّر هذا الاحتمال؟ بالعدّ: كم مرة جاء "ب" بعد "أ"، مقسوماً على عدد مرات "أ".

الخسارة والحيرة

خسارة النموذج على الجملة الأولى: متوسط سالب لوغاريتم احتمالات خطواتها الأربع، أي الإنتروبيا المتقاطعة من الدرس 14:

L=−ln⁡23−ln⁡1−ln⁡12−ln⁡14=0.405+0.6934≈0.275

والحيرة: الأسّ الطبيعي للخسارة:

e0.275≈1.32

التعلّم الذاتي الإشراف

من أين تأتي الأجوبة الصحيحة للتدريب؟ من النص نفسه!

كل موضع في النص مثال تدريب: المدخل ما قبله، والجواب الرمز الذي فيه. لا نحتاج أي إنسان ليكتب أجوبة.

self-supervised learning

نص من مليون حرف يعطي تقريباً مليون مثال. وهذا سر قوة النماذج اللغوية: كل النصوص في العالم بيانات تدريب جاهزة.

في الكود، الأجوبة هي نفس النص، مزاحاً خطوة واحدة:

x = data[:-1] · y = data[1:]

word_bigram.pyبايثون
import math
from collections import Counter, defaultdict

sentences = ["أنا أحب القهوة", "أنا أحب الشاي", "أنت تحب القهوة"]
counts = defaultdict(Counter)
for s in sentences:
    words = ["<s>"] + s.split() + ["</s>"]
    for prev, nxt in zip(words, words[1:]):
        counts[prev][nxt] += 1

def prob(prev, nxt):
    return counts[prev][nxt] / sum(counts[prev].values())

def sentence_prob(s):
    words = ["<s>"] + s.split() + ["</s>"]
    steps = [prob(a, b) for a, b in zip(words, words[1:])]
    return math.prod(steps), steps

p, steps = sentence_prob("أنا أحب القهوة")
loss = -sum(math.log(q) for q in steps) / len(steps)
print("P =", round(p, 4), " steps:", [round(q, 3) for q in steps])
print("loss =", round(loss, 3), " perplexity =", round(math.exp(loss), 2))
print("P(أنت تحب الشاي) =", sentence_prob("أنت تحب الشاي")[0])

count_bigram.pyبايثون
N = np.zeros((V, V))
np.add.at(N, (train[:-1], train[1:]), 1)              # count every (previous, next) pair
P = (N + 1) / (N + 1).sum(axis=1, keepdims=True)      # add-one smoothing, rows sum to 1

def nll(P, d):
    return -np.mean(np.log(P[d[:-1], d[1:]]))

val_loss = nll(P, val)
print(f"validation loss {val_loss:.3f} | perplexity {np.exp(val_loss):.1f} | "
      f"know-nothing baseline: loss {np.log(V):.3f}, perplexity {V}")
for c in ["q", "t", " "]:
    top = np.argsort(-P[stoi[c]])[:4]
    print(f"after {c!r}:", [(itos[j], round(float(P[stoi[c], j]), 3)) for j in top])

neural_bigram.pyبايثون
torch.manual_seed(0)
model = nn.Embedding(V, V)                  # row = previous char, columns = logits of next char
nn.init.zeros_(model.weight)                # start with a uniform prediction
opt = torch.optim.Adam(model.parameters(), lr=0.05)
loss_fn = nn.CrossEntropyLoss()

x_tr, y_tr = torch.tensor(train[:-1]), torch.tensor(train[1:])
x_val, y_val = torch.tensor(val[:-1]), torch.tensor(val[1:])
with torch.no_grad():
    print(f"step    0: val loss {loss_fn(model(x_val), y_val).item():.3f}")
g = torch.Generator().manual_seed(0)
for step in range(1, 3001):
    idx = torch.randint(0, len(x_tr), (4096,), generator=g)
    loss = loss_fn(model(x_tr[idx]), y_tr[idx])
    opt.zero_grad(); loss.backward(); opt.step()
    if step % 1000 == 0:
        with torch.no_grad():
            print(f"step {step:4}: val loss {loss_fn(model(x_val), y_val).item():.3f}")

تقييم النموذج على نص التدريب

خسارة التدريب لنموذج لغوي كبير قد تنزل كثيراً لأنه يحفظ. قِس دائماً على نص لم يتدرب عليه.

وانتبه للتسريب: النصوص المنسوخة، أو المكررة في الإنترنت، قد تظهر في التدريب والاختبار معاً.

سؤال مقابلة

سؤال قد تسمعه في المقابلة:

What does a language model compute, and how is it trained?

جواب قصير وجيد:

It computes a probability distribution over the next token given the previous tokens. By the chain rule, the product of these conditionals gives the probability of any sequence. It is trained with cross-entropy on the next token at every position of a large text corpus, which is self-supervised because the targets come from the text itself.

سؤال قد تسمعه في المقابلة:

What is perplexity?

جواب قصير وجيد:

Perplexity is the exponential of the average negative log-likelihood per token. It can be read as the effective number of equally likely choices the model is hesitating between at each step. Lower is better, and it is only comparable between models that use the same tokenizer and the same test data.

سؤال قد تسمعه في المقابلة:

Why do n-gram models not scale to long contexts?

جواب قصير وجيد:

The number of possible contexts grows exponentially with the context length, so the count tables become huge and almost all entries are never observed. Neural language models generalize across similar contexts through learned representations instead of exact counts.

الخلاصة
  • النموذج اللغوي يعطي احتمالاً لكل رمز تالٍ. واحتمال الجملة حاصل ضرب هذه الاحتمالات.
  • الثنائيات: الرمز السابق فقط، والاحتمال بالعدّ. والتنعيم يمنع الأصفار.
  • الخسارة: الإنتروبيا المتقاطعة للرمز التالي. والحيرة: أسّها الطبيعي.
  • التعلّم ذاتي الإشراف: الأجوبة هي النص نفسه، مزاحاً خطوة.
  • شبكة بسيطة وصلت إلى نفس نتيجة العدّ. وميزتها أنها تتوسع.
  • العدّ لا يتوسع لسياق طويل. نحتاج شبكة تنظر إلى كل السياق: الانتباه.

تلميح

مع التنعيم: العدّ زائد 1، على مجموع العدّ للكلمة السابقة زائد 7. وبعد "بداية" مجموع العدّ 3.

الحل (افتحه بعد أن تحاول)
  1. "أنا" جاءت بعدها "أحب" مرتين، ومجموع ما بعدها 2: (2+1)/(2+7)=3/9=1/3.
  1. أربع خطوات:
  • "أنت" بعد البداية: (1+1)/(3+7)=0.2.
  • "تحب" بعد "أنت": (1+1)/(1+7)=0.25.
  • "الشاي" بعد "تحب": (0+1)/(1+7)=0.125.
  • النهاية بعد "الشاي": (1+1)/(1+7)=0.25.

الحاصل: 0.2×0.25×0.125×0.25≈0.00156. صغير، لكنه ليس صفراً.

الحاصل: $0.2 \times 0.25 \times 0.125 \times 0.25 \approx 0.00156$. صغير، لكنه ليس صفراً.

```python
def smooth_prob(prev, nxt, k=7):
    return (counts[prev][nxt] + 1) / (sum(counts[prev].values()) + k)

words = ["<s>"] + "أنت تحب الشاي".split() + ["</s>"]
steps = [smooth_prob(a, b) for a, b in zip(words, words[1:])]
print(round(smooth_prob("أنا", "أحب"), 4), [round(s, 4) for s in steps], round(math.prod(steps), 5))
```
